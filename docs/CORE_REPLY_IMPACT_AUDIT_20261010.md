# 核心回复改造的功能影响检查

2026-10-10 的核心回复影响审计。普通回复由 AstrBot 完成，V2 通过原生钩子提供背景、工具和后台观察。路径说明见 [V2_CORE_REPLY_PATH_DESIGN.md](V2_CORE_REPLY_PATH_DESIGN.md)。

2026-10-11 更新：七项伴侣能力已改为 V2 本体内部原生拓展，分别配置和启停，随唯一 V2 安装包交付。下方 2026-10-10 的独立伴侣包及测试数量是历史记录；当前归属和新包验收见 [NATIVE_EXTENSIONS_REWORK_20261011.md](NATIVE_EXTENSIONS_REWORK_20261011.md) 及交付目录中的 `ACCEPTANCE_20261011.md`。

## 影响矩阵

| 功能 | 当前归属与本轮检查 |
| --- | --- |
| 私聊与群回复 | AstrBot 默认模型、工具循环、流式、结果装饰、自然段、TTS 与发送；V2 负责准入、背景和领域工具。验证核心真实 Process/Decorate/Respond 阶段。 |
| 人格与会话 | 当前人格与原生 conversation ID；首次会话、人格切换、修改人格、重置及热重载后重新绑定后台 owner。 |
| 群参与、复读与 Laya | 保留群准入、旁听与复读动作。Laya 历史按真实事件 ID 排除当前消息，保留同成员同一秒的其他消息；中文“吗”问句可进入判断。 |
| 输入、回复与发送历史 | 原生输入、生成观察和发送返回分别记录；只有真实发送返回可进入回复历史，不把生成或未知结果当作平台送达。 |
| 撤回、重置与 typing | 撤回使原生证据和派生样本失效；重置关闭当前回合、过期查询会话和 typing，不重放模型及发送。 |
| 私人记忆与经历 | 原生输入和发送观察进入可召回来源、反思材料与日常消费者。修复习惯视图误作为经历索引的异常；用户习惯与已完成生活经历可同时存在。 |
| 群公共记忆与互动 | 绑定原成员、角色和群；群经历合并本群成员发言及已发送回复，排除未发送内容和其他群。私聊资料不进入群。 |
| 表达、称呼与语义学习 | 原生发言进入熟人计数、用户习惯、风格样本与群黑话学习；管理页可复核原生样本证据。学习和图片下载在后台，撤回后不采用。 |
| 日记与自省 | 日记材料及自省证据读取原生历史。未发送草稿不伪装对话；原生发送返回保留“未获平台送达确认”的事实。 |
| 生活、状态、睡眠与周期 | 当前窗口绑定生活例行、状态维护、心情统计与日常调度；原生回合结束解除前台忙碌，晚安及用户回归进入屏幕后续机会判断。 |
| 日历、成长与关系 | 规划输入读取原生用户报告；原生工具使用本轮真实证据提交日历命令、成长与关系提议，保留既有确认语义。 |
| 主动灵感、新闻与提醒 | 原生完成回合进入当前私聊的灵感池，后续入站使旧机会失效；新闻原文默认不展开，追问工具读取原来源。主动联系和提醒继续使用独立任务。 |
| 原生外部工具 | 真实调用 ID、provider、context、task 和 receipt 绑定。后续消费者直接复核原生操作，未知结果不换编号重放；不创建假回复任务。 |
| 图片生成、编辑与相册 | 原图交核心缓存及视觉；补齐原生图片进入相册、分页、引用和日志。撤销来源后不可用。原生图片读取配置额度和请求开关；重复读取同一次结果不重复计数。 |
| 屏幕 | 原图交核心视觉；后台解读读取原生回合的角色提示，并产生后续日记材料。后台解读调度异常不使已成功采集的原图失效。只用合成图片测试。 |
| 作品 | 真实 Content owner 完成创建、读取固定版本、续写候选、采用与撤回。小屋作品摘要修复 JSON 解码，统计原生候选及实际更新时间。 |
| 游戏 | 原生终局 receipt 进入私人经历；未完成、关闭或未知结果不伪装终局。使用实际 Game provider 的合成牌局验证。 |
| 表情与内部拓展 | 表情原图经 MCP 返回核心，发送返回后计用量；Together、Reality、Live 的执行器属于 V2 本体，保留内部模块身份和授权调用合同。 |
| 治理页与回复诊断 | Token 合并核心、历史 V2 和附加任务且不重复；缓存只统计 Provider 实报。效率显示核心发送返回及真实模型、工具耗时；回复诊断可见原生回合，不伪造 V2 分段回执。 |
| 数据、备份与生命周期 | V2 独立数据根；合成旧库迁移、数据完整性和备份检查。新解包副本验证唯一小屋注册、加载、停机与路由注销。 |

## 配置的适用范围

普通聊天的 provider、fallback、流式、分段、TTS、引用及平台媒体发送使用 AstrBot 当前会话设置。小屋保留并消费 V2 附加提示、风格、拟人表达、领域权限与额度、后台学习和主动联系设置。

旧普通回复的 JSON 合同、批次分段、V2 被动 TTS、文件转述、群图片审阅及私聊转送不能作为核心聊天的第二道阻塞流程。已有独立任务和历史读取继续使用各自合同；回复页已说明这些旧配置的适用范围。群图片审阅及私聊转送原本默认关闭，本轮未把它们插回核心普通回复。

## 夹具与历史断言的适配

本轮将 Screen 授权测试改为宿主实际使用的内置提供方；多账号目标测试使用当前账号和私聊目标合同；群经历材料保存完整原上下文。主动诊断和图片日志的 SQL 替身分别返回原生与旧记录，避免把旧批次误当成原生记录。

记忆反思和多目标后台队列从原生输入证据开始，不为准备后台任务额外启动旧普通回复。管理 API 比较操作前后的发送记录，验证管理操作没有新增平台调用；群管理员降权后的查询保留已固定目标，不通过另一次旧回复获取目标。历史分段断言验证实际消息边界；末尾换行不作为必须内容。工具续轮耗尽后的旧独立任务验证本地故障提示及没有额外工具执行。以上改动只调整测试夹具和过时预期，不恢复普通回复的 V2 生成或发送路径。

录制公共 RSS 正文按现有构建规则不进入交付包，依赖该录制正文的端到端用例会明确跳过。合成资讯、原生新闻追问及主动源生产器仍在新包中测试；真实新闻站点、模型、TTS、图像后端、真实 QQ 客户端显示和生产性能不在本地替身验收范围内。

本文件随候选源码打包。最终测试数量和通过状态以新解包后实际生成的结果为准；源码阶段定向检查、全库旧基线及上一轮 CORE_REPLY_ACCEPTANCE_20261010.md 均不能替代本次包验收。
