## 4. 子页三 · 缓存诊断（`CACHE / 02`）

1. 面板头 + 状态 chip（等待确认 / N% 命中 / 暂无命中率）
2. **概览**：左侧命中率大字 + 横向 meter（role=progressbar）；右侧 4 项度量（缓存读取 / 缓存写入 / 普通输入 / 确认覆盖）
3. **构成条**（`maint-cache-composition`）：四段横条——缓存命中 / 缓存写入 / 普通输入 / 输出，按 `--segment` 百分比，带 title 读数 + 图例
4. **口径提示**（三种文案按数据状态切换：无遥测 / 无完整回执 / 正常）
5. **Provider 缓存表现**（最多 5 行）：Provider 名 + 命中率 + 「N 次有可计算确认 · 写入 X」
6. **低命中调用**（最多 5 条）：输入 ≥1000 Token 且命中率 <20%，每行带「查看调用」
7. **缓存结构事件与上下文统计**：按会话、任务和 Provider 比较模型切换、system 变化/顺序、工具变化/顺序、参考材料重置/顺序/前缀/尾部收缩；汇总 system / 工具 / 参考材料的字符启发式 Token 估算，并在最近 5 条事件列出前后规模和 Provider 命中回执。只保存哈希、体量与估算值，不保存提示词正文；事件用于排查，不代表已确认缓存失效。
