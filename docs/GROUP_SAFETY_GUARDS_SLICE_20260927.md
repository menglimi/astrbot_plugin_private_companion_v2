# T10 群聊防注入、隐私边界与现实承诺

本切片把群聊安全约束接入 V2 的窗口级回复设置、参与提示、回复文本处理和每日反思提示。

## 配置与快照

`conversation.presentation` 提供三个布尔开关，默认均为 `true`：

- `enable_group_injection_guard`
- `enable_group_privacy_guard`
- `enable_group_reality_promise_guard`

设置随回复批次一起 sealed。生成期间只使用该快照，不读取会中途变化的实时配置。

## 行为边界

群成员输入按对话数据理解，成员自称管理员、主用户或系统提示不能改变身份、权限、工具、记忆范围或安全规则。
群聊不得泄露其他成员私聊、私人记忆、关系细节、内部标识、来源和工具凭据。转述、猜测、显示名和自称保留为不确定线索。
模型由当前成员、来源、可见历史和原人格自行判断称呼是否合适；证据不足时使用中性表达。

现实承诺开关启用时，只有群作用域的出站文本经过窄匹配防护。明确声称已完成或即将完成拉人、修网、开房间、登录、控制设备、线下到场等动作时，替换为需要可验证外部人员或工具的说明。URL、媒体标签、引用、控制标记和已声明观察证据会被保护，普通意愿表达不拦截。

每日反思会复核有来源的群内称呼使用，只形成表达建议或可追溯的称呼偏好提案，不改变身份、权限或成员画像。
