# 我会永远陪着你 V2.0

版本：2.0.0 · 整合日期：2026-09-26 · 声明兼容 AstrBot >=4.27.2,<5，验收基线为 4.27.2。

本版把已经落地的 V2 领域框架、AstrBot 宿主和体素小屋组织为一个可安装插件。插件目录为 `astrbot_plugin_private_companion_v2`，拓展页的正式入口为 **我会永远陪着你 V2.0 → 陪伴小屋**。

## 安装包

- `astrbot_plugin_private_companion_v2-2.0.0.zip`：V2 本体，包含运行代码、配置 schema、小屋与管理工作区、测试与构建工具。
- `companion-v2-2.0.0-suite.zip`：完整交付包，包含本体 ZIP、七个可选伴侣插件 ZIP、安装说明、模块清单及 SHA-256 校验清单。先解压，再按需导入内部的插件 ZIP；外层套件不能直接作为一个 AstrBot 插件安装。
- `release-manifest.json`、`SHA256SUMS.txt`：记录各插件版本、文件数量、包哈希和接入层次。可选插件保留自己的版本，未伪装为 V2 本体代码。

已安装本体的本机可直接从 Dashboard 打开小屋。其他安装环境在 AstrBot 插件管理中导入本体 ZIP，或将 ZIP 内唯一的插件目录放入 AstrBot 的 `data/plugins/`。依赖由 `requirements.txt` 声明；Windows 使用 `tzdata` 提供时区数据。

## 已整合的框架

| 范围 | 本版包含 | 使用位置 |
| --- | --- | --- |
| 会话宿主 | 私聊、群聊、多 Bot、多账号、多角色绑定，消息合并与分段回执 | 原聊天渠道；小屋宿主管理 |
| 记忆 | 有来源的事实、经历、检索、反思、修订、历史、遗忘及群公共记忆领域服务 | 小屋「记忆与经历」；群管理仍通过已有 API |
| 关系 | 关系背景、情绪事件、审阅、采用、修订和撤回 | 小屋「人物与关系」 |
| 连续生活 | 个人阅读、原文书架、睡眠、日记、梦境及持久排程 | 日记书桌、阅读角、睡眠与梦境 |
| 角色状态 | 饥饿、健康、睡眠、周期、共享作息、日历和 QQ 展示诊断 | 小屋「日程」及「角色状态」 |
| 成长 | 技能、长期目标、来源、版本和审阅操作 | 成长花架、「目标与成长」 |
| 媒体与来源 | 图像、音频、视频、引用和合并转发输入；私聊/群聊原图投递、图文回执、再次引用与来源撤回复核 | 已接入的对话主链 |
| 主动与后台 | 便签/提醒、主动联系、免打扰、后台队列、公平调度、预算和未知结果恢复 | 领域服务、原角色工具及已有管理 API |
| 公共底座 | 身份授权、来源治理、配置继承、能力目录、模型网关、SQLite 正本、诊断修复 | 统一运行时与宿主 |
| 小屋工作台 | 体素庭院、天气/时段显示、房间布置、真实总览、家具入口、统一对象/角色选择 | 陪伴小屋首页 |

这些框架共用 V2 的运行时和数据边界。领域服务已实现不等于每项都有独立页面；未完成的页面不会以虚构记录冒充真实业务。

## 可选伴侣

| 插件 | 既有能力 | V2 本次接入 |
| --- | --- | --- |
| Content | 创作、作品版本、空间联动 | 原生作品提供方与 V2 宿主消费；创作书架、安装和公开状态 |
| Image | 生图、改图、参考图库 | 原生生成/采用/投递链；私聊多参考和蒙版局部编辑；安装与公开状态 |
| Together | 共读、观影、通话 | 共处电话、安装和公开状态 |
| Game | 房间与共同游戏 | 游戏棋桌、安装和公开状态 |
| Screen | 屏幕来源、观察与自动化 | 原生单次截图、V2 原件和模型图片上下文；屏幕台、安装和公开状态 |
| Reality | 设备、现实来源、手机终端 | 现实设备台、安装和公开状态 |
| Live | 直播、角色呈现、VTS/SoulLink | 直播入口、安装和公开状态 |

七个提供方均提供 `extension_api.companion_v2_status()` 元数据接口。接口只返回 schema、插件 ID、配置开关和可选就绪状态；不会读取对话、作品、图库或设备内容。原插件正常更新/重载后接口生效。运行中的旧实例若尚无此接口，小屋显示「已安装 · 待加载适配器」，不会误报已连接。

Content、Image 和 Screen 已有 V2 原生提供方及宿主消费链；提供方仍持有各自操作、配置和数据。Screen 的原生模式默认关闭，只有显式绑定设备、平台实例、Bot QQ 与 V2 Bot ID 并授予当前私聊能力后才允许单次采集；不会启动旧版自动观察。Together、Game、Reality 和 Live 目前仍为目录和状态接入，不能由 V2 对话直接调度。部分原插件对旧陪伴核心的依赖仍按自身实现保留。Dashboard 沙箱不允许页面自行切到其他插件，详情会列出对应插件与已有拓展页名称，可从 AstrBot 插件列表进入。

旧版陪伴核心仅作为兼容状态项展示，不包含在套件中；本版不读取、迁移或修改 V1 用户数据。

Live 包包含 AstrBot 插件、直播页面与运行所需 SoulLink 模块；不包含个人 Live2D 模型、模型密钥、桌宠安装程序或该独立客户端的本机配置。需要桌宠/VTS 时使用其已有独立客户端。

## 配置与运行

1. 在插件配置中设置单目标 `staging`，或启用 `multi_host` 并配置目标/角色映射。已有兼容键名继续使用，避免破坏原 V2 配置。
2. 保存并重载 V2。打开小屋 → 开始使用，先选择单/多账号与单/多人格，再在核心管理员私聊窗口发送固定绑定指令并确认。
3. 绑定确认后配置插件模型，再补世界知识、关系教学和主动消息测试。向导完成后不会要求每次使用插件都重新配置。
4. 正式运行固定使用 `onebot_private`，没有正式 `preview`/草稿投递模式，也没有“十年权限”或额外投递授权步骤。旧配置里的 `delivery_mode: preview` 只在读取时归一化为 `onebot_private`。
5. 真实投递仍须通过已绑定的账号、平台、私聊对象、人格、按人权限和 admission 检查；模型参数变化不会阻止固定运行实例连接。安装或重载不会自动启动会话接管，显式连接后才处理匹配目标。
6. 小屋顶端选择会话对象和角色。首页、记忆、关系、状态、生活和成长使用同一选择；切换对象或失去权限时清空旧内容。
7. 可选插件按需安装或更新；其配置继续在各自插件中维护。

V2 使用独立数据根，已有 V2 Profile/installation 继续按原契约读取。不要把旧数据库复制为 V2 运行库。
V1 配置迁移采用只读检查、试算、再写入 V2 的单向流程：配置台账逐键审计，403 条通用规则覆盖 V2 配置注册表、插件设置和语义目录，账号/目标/人格及天气、分段、技能强度另由专用转换器处理。无法表示或仍未实现的配置会在试算中说明，不会按相似名称硬写；V1 原数据不被修改。记忆、关系档案、工作/投递记录和世界资源等用户数据仍不属于此配置迁移范围。

## 页面与数据边界

- 小屋是唯一公开 V2 拓展页，不再以 Content 静态预览目录作为规范源。宿主、日记生活、关系记忆三个工作区的源码入口改为 `workspace.html`，保留完整功能并从小屋进入；Content 预览移至 `design-previews/companion-v2/`。
- 宿主内首页读取真实的生活、状态、记忆、关系和成长摘要；无记录时为空，不显示设计样例。
- 独立工作区被构建为小屋内部资源，通过已登录 Dashboard 的消息桥复用原 API，适配 AstrBot 的 opaque-origin iframe 沙箱。
- 天气实况使用明确配置的角色地点；感知总览显示当前读数，私聊询问天气时按需读取，日常计划可参考。关闭天气感知后不读取天气源，也不访问精确 GPS。场景时段和家具摆放仍属于显示偏好；沙箱禁止本地存储时，布置仅保留当前页面会话。
- 衣柜是陈设；没有新增衣橱、换装或手账业务。见闻电台尚未接入新闻工作台。
- [群聊已有原图出站](CORE_GROUP_IMAGE_DELIVERY_20260925.md)已通过本地模型替身和真实 SDK 验收；Image 原生生成、编辑和局部编辑有合成回归，真实后端与 QQ 客户端效果仍需现场验收。群聊蒙版局部编辑明确关闭；群语音/视频出站、真实多账号连续运行、完整模型/提示词/主动联系管理页面也仍需后续工作。已有模拟/SDK 检查不等于这些平台效果均已验收。

## 构建与验证

所有源码文本采用 UTF-8。打包使用允许目录与文件清单，跳过用户数据、缓存、日志、凭据配置、个人模型和构建产物；每个 ZIP 可单独安装。构建脚本对代码语法、JSON、版本、页面清单及常见凭据模式进行检查，敏感值不输出。

```powershell
python -X utf8 tools/sync_framework_page.py
python -X utf8 tools/sync_framework_page.py --check
python -X utf8 tools/build_v2_release.py --output <交付目录>
python -X utf8 tools/verify_v2_release.py --release <交付目录> --extract-to <新的验收目录>
```

构建脚本会从同级目录收集七个可选插件。只构建本体可加 `--core-only`。验证脚本检查包哈希、文件清单、语法、默认设置和唯一公开页；配好 AstrBot 测试环境后可加 `--host-check` 验证解压副本的临时宿主。页面静态设计预览可用 `tools/sync_framework_page.py --preview <预览目录>` 单独发布；静态预览不提供 Dashboard 业务连接。

本次定向验收记录在 [V2.0 整合验收](INTEGRATION_ACCEPTANCE_V2_0.md)；Screen 原生接入、真实本机截图隔离验收及新套件验证见 [Screen 接入记录](SCREEN_NATIVE_HOST_INTEGRATION_20260926.md)。完整历史及尚未完成的领域事项见 [构建状态](BUILD_STATUS.md)。
