# 群聊行为学习与模仿

版本：2.1.29。入口：陪伴小屋 → 学习与成长 → 行为模仿。

## 实际行为

角色可以从群友真实发言中学习互动方式，例如忙完后互相安慰、@ 熟人说「摸摸」、一起接梗。记录包括适用情境、动作、对象与边界、原始证据、对象反馈。多数人参与不能推断为每个人接受，角色自己的输出不作为学习证据。

观察阶段不调用模型。学习、参与选择、动作准备和反馈使用当前 AstrBot 主回复链的原生工具，不另开 V2 模型请求，不占用插件后台模型预算。学到的入站线索只准入一次模型参与判断，不直接发送。未被点名时先选择参与或旁听，学习和反馈可以与旁听决定同批执行。

`group.behavior.plan` 只准备当前回复。对象从当前已认证群消息提供的成员句柄选择；当前回复首个文字段添加 SDK 原生 At，后续文字段不重复 @，也不额外引用触发消息或 @ 触发者。发送前重新校验角色授权、模仿开关与习惯状态。仍使用已有发送边界和未知结果不重放机制。

记录区分准备、正在发送、发送调用已返回、失败和未知。调用返回不等同于平台确认。只有互动对象在调用返回后的真实发言可以作为该次互动反馈；旁观者、原有发言、尚未发送和未知结果不能算欢迎。没有回应不算喜欢。重复、生硬、忙碌、拒绝与新的边界交由主链提示词结合语境判断，不增加固定互动频次限制。

## 配置与归属

- `enable_group_behavior_learning`：学习和修订习惯，默认开启。
- `enable_group_behavior_imitation`：将习惯用于本轮互动，默认开启。
- `enable_group_behavior_feedback`：记录对象实际反馈，默认开启。
- `group_behavior_guidance`：角色的互动偏好，默认空。

角色默认配置供其群聊使用，保留既有按群细调层级。习惯归属安装、平台、Bot、账号、角色、群；不随成员原生窗口变化。成员个人习惯必须具有本人发言证据，不应用给其他成员。管理员停用的习惯不会被学习修订自动恢复。

页面通过所选角色的配置 API 读取记录并执行停用/恢复，管理员身份和乐观并发校验在后端执行。前端等待保存回执并重新读取状态，原始证据进行 HTML 转义，不向正式数据库写模拟数据。

## 验证边界

当前实现是新群消息驱动的自然参与，没有新增无人说话时的群广播或定时 @。自动学习及实际表达取决于主回复模型是否选择相应工具；工具链合成验证不能等同于真实群聊效果。验证不得主动向真实群发送测试消息。
