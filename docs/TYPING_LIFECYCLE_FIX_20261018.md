本机原来只有私聊 3996218846 保存了 `typing_enabled=true` 与 `platform.typing` 授权，近期实际使用的 995051631 没有这两项，因此不会触发输入提示。已通过 `StateConfigurationOwner.write` 给 995051631 当前绑定的星缘角色窗口启用，按现有规则签发精确窗口授权；其余窗口不变。配置维护回执保存在运行档 `maintenance/typing-995051631-20261018.json`。

原生回复的生成观察在模型完成时变为 completed，真实发送还可能继续二十多秒。输入提示改用独立回复租约，身份校验后的准备阶段开始，覆盖 Laya、主模型、工具与全部分段间隔；最后一段发送返回才释放。流式发送在外层发送结束后释放，工具的中间发送完成不释放；失败、取消、重置、撤权、停机停止刷新。重叠回复共享一条刷新任务，旧回复结束不会关闭较新的回复。
