# 主动联系全局默认与个人覆盖

## 保存范围

- 「主动与联系」的 `proactive.contact` 配置写入当前 V2 安装的 `installation` 层。页面不依赖选中的 Bot、人格或私聊对象。
- 「私聊用户」页的联系偏好写入当前可信私聊窗口的 `window` 层，地址包含安装、角色、用户及窗口路由。只写用户实际修改的字段，其余继续继承全局默认。
- 未显式保存全局值的字段保留旧角色默认。字段在全局保存后，以全局值和稳定的个人覆盖为准，不再被旧角色值遮蔽。公开页面不再创建新的角色或窗口层公共配置。
- 配置值与联系授权独立。保存全局或个人开关不签发、恢复或撤销用户能力授权。

## 旧记录兼容

旧公共编辑器曾将节律存入 WINDOW。未显式设置全局值的节律字段，按字段最近一次公共保存回执读取旧值，兼容开启和关闭。新全局值和稳定的个人值优先于旧公共窗口值、临时测试窗口开关；不会因更新另一窗口的备注而恢复更旧的节律。

兼容读取限定同一安装，保留原记录，不批量覆盖数据库。恢复范围是主开关、自动联系、免打扰、小时曲线、强度、间隔、burst、每日问候和失眠节律。私人备注、重要日期、来源与暂停不跨用户复制；临时 setup 开关不作为全局默认。历史回执缺失时仅对相同节律字段读取原值，完整性校验失败的字段继续采用有效默认。

旧私聊用户编辑器曾写入 `window` 或 `relationship`。兼容读取核对已完成的 `relationships.private-settings` 父操作与配置子操作地址，个人记录不会被提升为全局默认；已有关系级个人值继续作为窗口设置的兼容继承值，新保存则落到当前私聊窗口。重放旧保存时按原地址查找子操作回执，不会重新写入。

恢复为只读兼容值，不改写旧记录或签发权限；新个人字段优先。新个人清空暂停时，不再被同一人的旧窗口暂停恢复，祖先层的更晚暂停仍按原规则生效。重试已经完成的旧个人保存返回原子操作回执，不重新执行或生成不存在的新回执。

## 页面与路由

页面从安装级 `/config` 读取公共设置正本和编辑令牌。多目标模式下，此入口只开放 `proactive.contact`，并使用安装级管理上下文，不借用当前私聊窗口。刷新失败保留已确认的全局配置；未选择角色或私聊对象时仍可编辑全局配置。保存继续使用原操作标识确认未知结果。

节律控件编辑全局默认，不把全局开关显示成某个用户已获准或此刻可以联系。逐用户授权与私聊窗口覆盖由私聊用户页读取和维护；其中未显式设置的字段继续继承安装级默认。

私聊用户入口优先使用宿主保存的当前可信 ScopeRef。旧 conversation_routes 保留为历史，但同一账号和用户已有当前路由时不再把过期窗口列为同时可写的候选。身份、账号、角色和授权校验继续由既有管理流程执行。

## 验证覆盖

- 全局设置跨用户、Bot、角色及宿主重启保留，旧编辑令牌不能覆盖新设置。
- 私聊页覆盖写入当前窗口、不会覆盖全局默认；其他窗口继续使用各自覆盖或全局默认。同一窗口重启后保留，窗口路由变化后不把旧窗口覆盖带到新窗口。
- 旧公共节律只读恢复、字段时间排序、显式 false、新全局值优先、安装隔离和临时测试窗口不遮蔽正本。
- 旧个人记录与公共默认分离，旧关系级个人值仍可继承到窗口；窗口级新值独立生效，旧回执重试不重复写入。
- 页面重开、刷新、实时状态失败后的全局保存、稀疏提交与原操作结果恢复。
- 个人授权、公共保存不改授权、诊断准入与停机后的临时权限恢复。

交付验收使用本次源码构建的新包，在 AstrBot 自带 Python、临时 ASTRBOT_ROOT 和解压后的源码中执行相关回归，并执行宿主加载、停机及路由注销检查。只使用合成模型和投递夹具。
