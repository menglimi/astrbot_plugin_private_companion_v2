# V1 / V2 感知运行时差异

核对日期：2026-10-01。范围是源码与能力合同，不读取 V1 用户数据。

| 感知内容 | V1 实际能力 | V2 原有基础 | 本次补齐与现状 |
| --- | --- | --- | --- |
| 日期、时段、节假日、重要日期 | 普通对话注入时间日历及配置的重要日期 | V2 请求级日期/模型感知、角色日历和临近日期展示已接 | 已覆盖；不重复实现。 |
| 角色自身健康/心情/睡眠 | V1 日常状态进入角色上下文 | V2 State API 已提供当前角色状态 | 已在感知总览呈现；与手机传感器健康数据分开标注。 |
| 地点与天气 | V1 将配置地点的当前天气放入私聊场景上下文 | V2 原先只在计划/主动提醒和感知页读取，普通对话没有天气读取动作；共享新鲜度校验还漏掉了默认 QWeather 来源 | 新增 `weather.current` 私聊只读工具；仅当角色天气已启用且配置地点有效时提供，读取固定角色地点而不取手机定位，验证受支持来源、观测时刻和配置的新鲜度窗口。模型只在天气相关问题时调用。 |
| 屏幕识别 | V1 通过 Screen Companion 获取识屏能力及昨日摘要 | V2 已有受治理的 Screen 原件、模型解读和反馈锚点，但总览没有读回最近解读 | 新增私聊作用域的最近解读读取；每次展示都重新通过 ScreenRepository 校验来源和当前授权。撤回后结果不再显示。 |
| 手机位置、设备、活动、健康遥测 | Reality Companion 的 `mobile_context` 返回短期位置、设备状态、活动与遥测 | V2 `reality.snapshot.read` 已有私聊授权和原生工具；普通对话读取后会保存经治理结果 | 总览仅读取当前私聊里最近一次成功且当前仍获授权的结果；位置只显示区域标签、不显示经纬度。页面刷新不触发设备采集。 |
| Reality 摄像头识别 | V1 通过 Reality Companion 的 `camera_snapshot` 采集和分析，并保留独立用户知情确认、单帧策略与冷却 | V2 源码提供 `reality.camera.observe`、V2 独立授权和结果回显；是否可用取决于当前加载的 Reality 提供方及授权 | 仅当前私聊原始输入明确要求摄像头观察时才允许派发；V2 摄像头授权独立于手机摘要授权，Reality 原有用户确认、单帧策略与冷却仍由提供方复核。V2 只接收脱敏识别字段，不接收原图；总览仅读取当前私聊已成功的最近结果，撤权后不返回旧结果。 |
| 模型、平台和输入媒体 | V1 有对话模型/视觉及多种输入路径 | V2 按当前请求、实际目标模型和媒体输入建立感知合同 | 已覆盖；保留“本轮实际提供”的边界。 |

运行数据只绑定当前管理页选中的 V2 私聊对象和角色。感知总览只检查当前加载实例的提供方声明与授权；源码有实现不代表在线实例已加载提供方或已获授权。天气请求读取已配置的角色地点；Screen 与 Reality 结果读取前重新检查各自授权。没有从 V1 迁移、读取或修改用户数据。

## 页面配置承接

总览是一张全宽看板：时间、日期、星期和临近的重要日期在时间区显示，其余信号按紧凑状态行排列。点击状态行会切换到对应分区并展开目标子面板；预警、视觉模型、米家设备和本轮其他注入只在存在实际数据或已启用时显示。

| 看板内容 | 配置落点 | V1 对照与边界 |
| --- | --- | --- |
| 日期、星期、历法与重要日期 | `时间、日历与环境` 下的本地日期与历法、重要日子；分别编辑角色日历与 `proactive.contact` 日期字段。 | 承接日历上下文、农历/节气/黄历、重要日期、问候开关和提前关注天数。 |
| 所在地、天气与预警 | 地点与天气子面板；天气问候和官方预警在日期与天气设置中。 | 角色地点使用 V2 地点合同；天气源固定为宿主支持的 Open-Meteo / 和风预警，凭据由宿主管理，不保留 V1 每角色天气密钥与来源选择。 |
| 对话、TTS、生图与视觉模型 | 模型路线子面板；真实路由由模型与连接页和 AstrBot 语音 Provider 设置管理。 | 按当前任务路由展示；没有视觉 Provider 时不造一条空配置。 |
| 外部资讯、网络探索与自关联 | 外部资讯与检索子面板，包含 `news`、`web`、`selflink` 三个字段视图。 | 承接资讯来源、网络探索兴趣/间隔/条数与外部事件自关联。搜索凭据由宿主的实际搜索 Provider 提供。 |
| 用户定位、识屏与摄像头 | 设备与授权子面板，含 Screen 设置、Reality 私聊授权、摄像头单独授权与群图理解入口。 | 只回显当前授权作用域里已经完成的读取；页面刷新不会触发采集。 |
| 撤回记录 | 撤回记录子面板和 `recall` 配置。 | 保留当前私聊范围与转录时限约束，撤回内容只读展示。 |
| 米家设备 | 只读设备状态子面板。 | 仅当米家扩展开启只读状态并返回设备目录时显示；不为补齐看板而调用设备控制或主动查询。 |
| 其他注入 | 本轮上下文材料子面板。 | 只列出本轮真实注入的来源；相应配置仍由来源所属工作区负责。 |

其他输入与表达配置按用户指定归属：群聊成员线索在「关系与权限」关系网；语义理解与学习素材在「学习与成长」的学习/反思区；表情素材与检索在「表达」。这些不在感知页重复出现。
