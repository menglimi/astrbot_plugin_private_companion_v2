# 每轮阶段差异

2026-09-24。承接[周期连续性优化](ROLE_CYCLE_OPTIMIZATION_20260924.md)，新增可选的每轮阶段天数差异。用于角色自身的模拟；感受、语气及是否提及仍由原人格和材料决定，日程、聊天压力及情绪不改写日历。

## 当前行为

新增 `role.state.cycle_variation_enabled`，默认 false。在原 state 管理 API 的 `configure.changes` 中设置 `cycle_variation_enabled: true` 即可，权限、版本检查和操作回执继续沿用原入口。

- 每轮可以采用基础方案，也可以在两个阶段间移一天：其中一个阶段加一天，另一个减一天，其余阶段不变。允许相邻两轮方案相同。
- 周期总天数仍为配置的各阶段总和。本批实现阶段长度差异，没有增加周期总长的随机浮动。
- 六阶段仍各为 1–30 天；基础模式的恢复期由四阶段合并，为 4–120 天。阶段不能被减为零或超出边界；全部达到同一边界时保留基础方案。
- 当前方案在本轮内固定。首次建立日期和 CORE 显式定位可立即采用当时配置；已有日期的开关、长度及模式变更在成功维护后保存为 `pending_plan`，统一从下一周期采用。
- 生效前可以撤销或修改待生效设置。关闭差异不重算当前阶段；关闭整个 `cycle_enabled` 仍立即停止周期材料投影。
- 没有日期、适用性未知或不适用时，不凭开关创建阶段。差异不自动增加不适、精力扣分或情绪变化。

例如，基础六阶段为 `5 / 7 / 2 / 2 / 9 / 3`，某轮可为 `5 / 7 / 3 / 2 / 9 / 2`，仍为 28 天。本例不是所有角色共用的轮换表。

## 保存、读取与重启

内部时钟沿用原状态版本记录，增加 `variation_enabled`、`variation_seed`、`variation_version` 和可选 `variation_plan`。后者保存本轮周期编号、起始日期、基础方案及实际阶段天数。模型输出不能提供或替换这些字段。

`cycle_variation.py` 中的第 1 版算法根据已保存种子、周期编号和基础方案确定结果。成功维护会保存本轮方案，同一轮的后续维护复用该方案。只读查询若已跨过保存时的周期，按相同版本和依据直接重建当前轮，不改写数据库、不调用模型、不逐轮补跑离线时间；下一次成功维护再保存当前轮快照。历史版本继续使用自身的依据和方案。

种子由受信任的角色/私聊归属和锚点确定并保存，后续换绑或重复维护不重新选择。停止差异后保留种子，重新开启从下一个生效边界继续使用；显式重新定位使用新定位的依据。算法版本随记录保存，固定测试样例防止以后无意改变旧序列。

修正了维护预览和正式保存初始化依据不一致的路径：二者现在通过同一角色归属计算。当“适用但日期未知”改为自然初始化时，生成前提供的阶段与成功保存的阶段一致。

## 管理与模型材料

配置示例：

```json
{
  "action": "configure",
  "operation_key": "enable-cycle-variation-1",
  "edit_token": "使用 GET 返回的 edit_token",
  "changes": {"cycle_variation_enabled": true}
}
```

已有周期在下一次成功维护后排入待生效方案。首次使用还需原有 `enabled`、`cycle_enabled` 和角色适用性成立；该选项不隐式开启其他功能。

有日期且本轮已采用差异时，`state.cycle_timeline` 增加：

| 字段 | 含义 |
| --- | --- |
| `variation_enabled` | true，表示本轮启用了阶段差异。即使本轮恰好沿用基础方案，也保持 true。 |
| `phase_plan` | 本轮实际采用的 `{phase, days}` 数组。`phase_day`、`phase_days` 及下一阶段日期均据此计算。 |
| `pending_plan.variation_enabled` | 有待生效配置时，表示下一方案是否启用差异；其 `phases` 仍为基础方案。 |

未启用的投影省略上述当前差异字段，保留旧时钟和已封存历史的形状；未有日期时不提供虚构的 `phase_plan`。内部种子不进入管理投影或模型材料。

维护提示词说明以本轮实际方案为准，不能把阶段差异解释成疾病、异常或确定症状。普通对话仅在使用差异时间线时添加这段说明，继续结合话题和最近表达决定是否提及身体感受。

## 来源和发送边界

每轮方案沿用独立周期来源，不依赖当天的无关情绪聊天。来源撤回后，对应的周期依据和方案仍会失效；撤回无关心情后，可以在合法维护中恢复原有效方案。没有扩大感受正文的可见范围。

新周期开始仍属于自然时钟推进，同一轮回复使用捕获时的周期材料。跨周期生成不会因此阻塞；人工改期、版本变化、功能关闭、撤权及真正的周期来源撤回继续复核。
