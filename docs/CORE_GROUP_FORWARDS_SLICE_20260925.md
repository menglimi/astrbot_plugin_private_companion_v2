# 群合并转发与嵌套节点

日期：2026-09-25

## 已落地

群合并转发沿用 `conversation/forwards/` 的节点清单、原件发布和依赖治理，没有复制私聊转发领域。新的 `adapters/astrbot/group_forwards.py` 只在固定 OneBot 账号连接上，按当前群、外层消息号及实际转发者读取一条原始群消息；随后核对返回消息的账号、群、消息号、发送者和 Forward 组件位置，再冻结展开节点。连接替换、返回消息错路由、错误发送者或宿主预处理后的正文冒充卡片都会拒绝受理。

节点文本、图片及嵌套节点按路径保留原顺序并链接到原群输入来源。节点中的账号、昵称和时间只作为未验证的转发显示归因；不会据此切换人物、认定作者或推断原受众。当前转发可以向模型提供获准读取的图片，后续群历史只显示转发记录和附件元数据，不重新向视觉模型呈现旧图片。

群转发读取历史仍受群受众、参与者和原始来源授权约束。撤回外层输入会撤销转发根、节点和附件依赖；重启后来源仍为 revoked，后续群历史不再包含该转发。首批只接入文本与图片；后续[节点语音、视频及采样帧扩展](CORE_GROUP_FORWARD_MEDIA_20260925.md)已接入相同来源链，验证结果和剩余边界见该记录。

## 验证

AstrBot 自带 Python 对群转发、群宿主、群媒体、群对话历史、私聊转发及 Reply 转发的 9 个受影响测试模块执行 **123 项回归，全部通过**。另对增强后的“撤回—重启—历史剔除”用例单独复验，通过。覆盖嵌套节点和图片原件、账号/群/发送者/组件核对、错误宿主预处理、历史图片元数据化以及依赖撤回传播。

测试使用本地 SDK 类型、合成 OneBot 历史和替身模型；没有真实 QQ/模型请求、在线重载或 V1 数据访问。复用现有 source、图片和群历史表，没有 schema 迁移或根级业务模块。
