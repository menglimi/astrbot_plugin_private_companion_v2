# 主链回复效率与插件注入

治理与维护的「近期回复效率」读取当前角色近七日的真实主链观察，按单次回复展示消息接收、请求准备完成、Agent 启动、逐轮模型请求、工具执行和原生发送返回。旧 V2 平台回执与核心发送返回继续采用各自计量终点。

本次补齐的插件准备包括素材构建、请求授权、提示词注入、领域工具注入和发送工具注入。素材条目仅记录固定来源名称、准备耗时、字符数和就绪/空/不可用状态；只有已存在于本次请求的素材标记为已注入。失败的可选素材不阻断其他素材或核心回复。记录在后台提交，沿用版本栅栏，不在请求钩子里写库。

「已观测模型请求累计」只累计实际逐轮请求的计时，不计入 Agent 汇总或末次工具重查回退观察。模型往返区间、工具执行累计、Agent 总时长与发送区间各有口径；工具可并行，流式发送可与生成重叠，这些数字不能相加作为总时长。Agent 完成与末次观测模型返回使用各自时间戳，零耗时不当作缺失。

没有采集到的历史阶段保留未观测。核心发送方法返回不能证明平台或用户已经收到，其他插件的普通钩子不计入本插件注入耗时。所有这些观察均不创建插件模型调用或预算预留，不保存提示词正文、工具参数或返回内容。

页面按回复标识保留样本的展开状态；手动和定时刷新统计不再收起正在查看的明细，主动收起仍会生效。

当前源码的交付包需重新构建并从解包副本运行主链统计、事件钩子、效率页面及宿主生命周期检查；验收以对应构建的实际结果为准。
