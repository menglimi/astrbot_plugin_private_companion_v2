## 运行时数据迁移

迁移目录覆盖 V1 `6.6.2` 与 `6.7.0`。当前安装元数据标记为 `6.7.0`（开发中）；只读核对显示核心 `companions.json`、表情目录和工作/相册 SQLite 仍符合现有转换器所读字段合同。6.7.0 新增的角色体素外貌保存在 AstrBot 插件 KV 中，V2 当前没有对应的角色外貌持久化合同，因此不映射到小屋主题设置。真实数据验收使用隔离 V2 数据根，V1 保持只读。

配置迁移与数据导入分开执行。配置转换仍由 `v2.private-config-converter` 等配置规则产出，数据迁移页只读检查来源，并要求用户选择 V2 目标/人格及确认必要的身份映射。

当前已接入的数据映射：

- `companions.json` 与 `persona_profiles`：带日期的角色日记和当日梦境写入 V2 角色日记；日期冲突不覆盖，按 100 条、2 MB 分批。无日期梦境碎片和私人画像不迁移。
- `worldbook_entries`：普通条目进入角色知识目录；成员条目转换为只读归因线索，需确认账号 ID；群条目按所选 V1 群和当前 V2 群映射。预览不显示正文，超过单条/总量限制或范围无法识别的条目会列出原因。已禁用的成员条目会跳过，因为 V2 成员线索没有禁用状态。
- `groups.relationship_edges`：只转入成员计数、时间范围和汇总互动边，不导入原话。目标必须是群会话并确认成员与群映射；V2 上限外的成员/关系边会在预览列出数量。
- `reaction_expression_library` 和 `owned_reaction_assets`：校验路径、图片类型、大小和哈希后按素材内容去重导入；素材是否启用沿用 V1 状态。

V2 群关系图可保存最多 512 位成员和 512 条关系边；超过容量的内容仍在预览中显式计数。当前安装的群图试算包含 4 个群，最大的图有 375 位成员与 81 条边，不再被旧的 256/80 容量截断。

工作/投递库按设计跳过，因为旧任务与外部发送回执无法在 V2 当前身份/授权下复核，不能重放；相册及图片资源归 Image Companion 持有，不复制外部引用；私人用户画像、世界书成员档案和无日期梦境碎片缺少可靠的 V2 主体归属或等价合同；扩展数据仍按各扩展所有者处理。记忆库保持原位只读，Content、Image、Reality 数据归各自插件。

因此，核心档案中可安全映射的数据已进入独立的预览/确认/导入流程；这不等于所有 V1 数据都复制到 V2，也不构成对真实 V1 版本、字段组合或运行现场的验收。
