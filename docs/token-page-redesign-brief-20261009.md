# Token 统计页重设计 · 文字版方案（v1）

> 前置阅读：`docs/maintenance-current-state-20261007.md`（现状精确还原）。
> 范围：治理与维护 → 子页一「Token 统计」。页头与二级导航为五子页共用，本方案默认不动。
> 日期：2026-10-09

## 一、功能与需求理解

页面本质：角色账本的**用量仪表 + 成本可解释性**。宿主的四个核心问题：

| 用户问题 | 数据支撑（现有字段） | 现状呈现 | 现状毛病 |
|---|---|---|---|
| 现在用了多少、预算还剩多少 | `budget.spent_tokens/held_tokens/limit_tokens`、summary tokens、calls、余额查询 | hero 大数字 + 136px conic 预算环 + 8 项 KPI | 答案被 KPI 平铺稀释 |
| 花在哪了 | provider/kind 排行 Top8 + 明细表（8–9 列） | 双栏排行卡 | 次数与 token 比例不直观 |
| 划不划算 | 缓存命中/写入、确认/估算、延迟、失败 | 8 项 KPI 四列平铺 | 无主次；"不估算"占一格 |
| 趋势与异常 | 14/7/30 日柱图（可点）、48h 分布、周期对比 | 双栏柱图 + 对比卡 | 柱图是配角，与读数脱节 |

硬约束（继承既有铁律）：

- **零编数**：无字段不显数；外部来源（记忆插件 / 一起房间 / 主链）未接入时保持"未连接占位 + 三条边界声明"，绝不混算。
- **口径诚实**：已确认 vs 估算、本地计价 vs 服务端余额，声明必须始终在场。
- 6 套主题（light/courtyard/dusk/night/walnut/contrast）共用一套组件，token 化。
- 容器：`.shell` 内容宽 = 视口 − 92 − 60，上限 1660。
- 第一版不动后端数据合同，纯前端重排。

## 二、信息架构：五段单列堆叠 → 「一条主线 + 三个抽屉」

### Zone 0 · 驾驶条 LEDGER STRIP
整宽一条，四根 hairline 分隔的一级读数横排：

1. **本期 Token**：大数字 + 周期 label + N 次调用 + 环比（up/down/flat）
2. **预算余量**：百分比大数字 + 细横条三段（已入账 / 预留中 / 硬上限）
3. **缓存命中率**：大数字 + 命中/写入小字
4. **信号**：失败数 + 未确认数 + 软限额状态，异常时红/黄

其余 4 项 KPI（输入/输出、平均每次、平均延迟、调用确认率）降级进 Zone 4。

### Zone 1 · 口径行 CALIBRATION ROW
一行小字收拢：数据源 chip + 口径声明（Provider 确认 / 本地计价）+ 余额查询 + 「统计口径」details。取代面板头内重复的盾牌说明。

### Zone 2 · 主趋势 CHART STAGE
全宽日柱图升为唯一主角；小时分布改为右上 tab（日 / 时）。柱可点，选中日联动驾驶条①副行与最近调用筛选。

### Zone 3 · 构成账本 BREAKDOWN LEDGER
Provider / 任务两组排行去卡片化，改**账本行**：序号 + 名称 + 比例条 + 右对齐 tabular 数字 + 次数 + 操作（齿轮 / 漏斗）；明细表行内展开。

### Zone 4 · 明细抽屉 DRILL DRAW
周期对比、每日明细、次级 KPI 全部收进 details，默认折叠。

### 外部来源态
驾驶条显示"未接入"，Zone 2–4 显示现有边界声明卡 + 返回按钮，不整页替换。

## 三、视觉语言（前卫方向三选一）

| 方向 | 要点 | 风险 |
|---|---|---|
| **A · 控制室 CONTROL ROOM（推荐）** | 去卡片化：整页一块仪表板，区块间 1px hairline（--t-border）+ 留白分隔；数字主角化（56–72px tabular-nums 等宽）；标签 11px 全大写 letter-spacing 0.12em；HUD 层级靠索引号（00 LEDGER / 02 CHART）、四角 tick 刻度、柱图加粗基线；呼吸椭圆等装饰退场 | 需严格执行，半途而废会显"没画完" |
| B · 瑞士账本 SWISS LEDGER | 浅底优先、超大黑体数字、红色仅超预算/失败、表格即设计元素（细线、右对齐数字、去斑马纹） | 克制有余，前卫感弱 |
| C · 终端流 TERMINAL STREAM | 全局等宽 + 荧光单色 + 扫描线纹理 | 与 courtyard/walnut 浅色主题冲突大；仅适合页头点缀 |

推荐 **A 混入 B 的表格处理**。hairline 体系全部走 6 主题 token，不写死深色。

状态色语义（全页统一）：确认/健康 = 主题 accent；估算/等待 = 琥珀；失败/超限 = 红。

## 四、交互细节

- 周期切换（今日/7日/30日/总计/按日期）移到驾驶条①右上角。
- 柱图点击 → 选中日高亮 + 驾驶条①副行变为该日读数。
- 失败/未确认读数可点 → 跳最近调用对应筛选（复用现有漏斗）。
- 预算横条 hover 展开三段读数；≥90% 条尾出现警示刻度。
- 空态诚实：新角色数字显示 0 不隐藏；趋势区引导"首次调用后出现"。
- 零编数红线：无"按日排行"字段前，柱图点击只联动最近调用，不前端估算排行。

# v2 · 概念升级：层积光谱带 THE STRATA（2026-10-09 晚）

> 用户反馈 v1「没有一眼惊艳、与 UIUX 交相辉映的设计感」。v2 从"排版重构"升级为"标志性装置"：装饰即数据，UX 即视觉。

## 核心装置

把「趋势柱图 + 预算环 + 缓存构成条」熔成一个全宽**层积光谱带**，整页脊柱：

- 每天一片**层积岩**，自下而上：缓存命中（发光核心）→ 普通输入 → 输出（最亮 accent）。数据源：daily 行已有 `input_tokens/output_tokens/cached_input_tokens/cache_creation_tokens`，分层是真实数据。
- **预算天花板线**取代预算环：横贯带体上沿；≥90% 时红移 + 微脉冲（环境性危险态）。
- **口径诚实长在图形里**：含估算/未确认的天，岩层半透明纹理，无需小字声明。

## 三个惊艳瞬间

1. **开屏即答案**：带体从基线生长入场、岩层依次点亮；4 个一级读数 = 锚定带体、细引导线牵引的 HUD 标注（今日总量 / 预算余量 / 命中率 / 信号）。
2. **十字游标**：横移带体竖向准线跟随，右侧浮动读数盘展开该日全部维度；点击沉入最近调用。
3. **预算发烫**：天花板颜色/脉冲即预算状态。

## 统一视觉语法

- 构成排行 = **账本凹槽**（与带体同比例尺，凹槽深度 = Token 占比，等宽序号 + 右对齐 tabular 数字）。
- 口径行 = 带体下方**校准轨**（数据源 chip + 口径 + 余额 + details）。
- 次级 KPI / 周期对比 / 每日明细 → 明细抽屉折叠。
- 小时视图 = 48 根密集高频细柱，与日态质感对比。
- 数字 56–72px condensed/tabular；标签 10–11px 全大写宽字距；6 主题 token 化（深色=数据层辉光，浅色=墨水密度叠加）。
- 动效仅三处：入场生长 / 游标跟随 / 预算发烫，全部承载信息。

## 诚实降级

- 小时粒度只有总量时，"时"视图退化为单色柱，不造分层。
- 无"按日排行"字段前，游标选中某天只联动最近调用。

## 备选

- B · 心电图 PULSE：48h 脉冲线做背景，KPI 悬挂峰值——轻盈但承载弱。
- C · 墨水账本 INK：纯排版、无装置——最安全最不惊艳。
