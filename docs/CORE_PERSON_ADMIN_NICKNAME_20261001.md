# 管理员称呼写入切片

日期：2026-10-01。范围：在关系与权限页为当前 V2 相识目录中的人物设置管理员称呼；不改变平台昵称、账号身份、关系阶段或 V1 数据。

## 行为

- 相识卡在平台资料名之外保存 `admin_nickname` 与更新时间。展示优先级为管理员称呼、当前群名片、平台昵称。
- 关系与权限详情允许核心管理员设置或清除称呼。清空并保存会移除管理员称呼，页面恢复显示平台资料。
- 唯一写入口为 `POST /astrbot_plugin_private_companion_v2/acquaintance/admin-name`。请求只能指向当前加载配置中的 Bot/角色路由；服务还会用 subject、原生账号和相识卡路由逐项核验，不能通过改请求字段编辑目录外的人。

## 写入约束

- 操作者必须是已登录的 Dashboard 管理员，并通过 `memory.manage` 检查。
- 请求携带卡片 revision。并发变更后旧 revision 返回冲突，页面刷新后再编辑。
- 每次写入通过操作账本保留原结果；同一操作键和相同参数重放返回原回执，参数不同则冲突。
- 仅在称呼实际变化时推进卡片 revision；管理员称呼最长 64 个字符。清除称呼也走同一 CAS 与操作账本。
- 领域代码位于 `companion_v2/memory/person/admin_names.py`；宿主路由位于 `astrbot_host/acquaintance_api.py`；编辑器位于 `pages/关系与权限/app.js`。

## 验收范围

定向测试覆盖管理员称呼优先级、清除后回退到平台资料、revision 冲突、幂等回放、越出当前目录路由的拒绝、Dashboard 身份与管理权限，以及页面保存和错误状态。该功能不创建身份别名，不合并不同平台账号，也不读取或迁移 V1 用户资料。
