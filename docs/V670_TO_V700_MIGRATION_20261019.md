## 本轮补齐

- 补齐 REQ-041 本体私聊记忆迁移，按旧机器人账号和真实用户确认身份，写入角色历史库。
- 补齐六阶段状态配置、附加任务模型策略和已注册任务超时的转换；普通对话沿用 AstrBot 当前模型路由。
- 普通回复支持日期和自然语言检索迁入资料；长资料按当前提示词预算分页取片段，保留正文验证能力。
- MemoryCompanion 的导入批次按目的地隔离；更新一个目标时保留其他角色和群资料，并兼容已有共享批次。
- 日记导入回执不再依赖无关目录变化；旧回执无法识别时，直接核对正文一致性，不覆盖人工修改，也不伪造回执。
- 升级核验识别插件控制器实际生命周期，重建路由不会被当作重载；重新加载插件即可重新采用保存的插件配置。
- 陪伴小屋提供本体记忆核对与导入、旧工作归档查看入口；切换来源/角色后废弃原试算，丢弃异步返回的过期结果。
- 已有宿主验证的 API Key 以独立服务身份访问迁移入口；未经过宿主认证上下文的身份字符串不予接受。

## 保留边界

旧工作、版本、调用与投递记录按原结构保留，可经管理员归档接口检视；旧 job、未确认投递、情绪和承诺不恢复为活跃任务。普通对话的主模型、路由和拒答回退由 AstrBot 管理，不将未被实际消费的配置伪装成已生效。

本次没有运行本地 Laya。交付验收从当前源码新建的 ZIP 解压目录执行；包校验、宿主生命周期、迁移测试及页面测试的最终结果保存在交付目录的核验报告中，旧包验收结果不作为本包证据。

真实历史库已通过只读连接执行普通回复使用的历史上下文函数；身份、角色和权限使用实际持久化目录解析。自然语言及日期提问均返回非空资料，篡改为另一角色后读取被拒绝。检查仅回读资料，不调用模型、不向聊天发送测试消息。
