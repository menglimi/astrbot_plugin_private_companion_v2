# V2 原生 Image：生成、采用与投递

2026-09-25。本批沿 [原生重构分工](NATIVE_REFACTOR_COORDINATION_20260925.md)推进。Image 保留原可选插件身份，新业务由 `image_companion/native_v2/` 负责；V2 本体通过统一协议调用，不委托 V1 私有执行入口。本文记录源码增量，已交付的旧套件 ZIP 没有被重打或覆盖。

## 已落地链路

1. AstrBot 宿主发现当前启用插件的稳定 `extension_api.companion_v2_native()` 端口，核对插件、包、声明与实际对象身份。登记声明、选择包、角色启用和用户授权分别处理。
2. 已授权的 `image.generate` / `image.edit` 进入 V2 独立子任务，携带原身份、角色、受众、请求与截止时间。Image 原生 owner 使用独立 SQLite 保存操作、不可变产物和回执。
3. 宿主按原 artifact 标识读取 bytes，核对 SHA-256、大小及真实图片编码。V2 生成图片 owner 保存受治理的清单、来源、资产及原件；不伪造用户入站消息，不把 base64 或文件路径写入工具正文。
4. 模型续答仅能增加本批真实成功、当前仍有权限的生成图。原输入图片、角色、音视频及既有上下文保持原合同，新增图片继续要求视觉模型能力。
5. 最终采用沿现有可发送图片句柄与回复清单，图片附于最后一段文字，交给 V2 sender。生成成功、角色选择采用、平台确认投递分别留据。
6. 私聊与群聊均可执行；群只开放这两个已授权图片动作。其他成员的后续群历史只得到元数据，引用已确认 Bot 图文时重新验证原件与原生成者授权。

## 治理、恢复与目录

- 生成图明确标记为提供方生成或编辑产物，不作为用户照片或现实事件证据。原输入、实际使用的工具来源与群历史依赖均保留原 owner 和撤回关系。
- 图片、帧和原件字节共用本轮预算。输入或已采用产物占满额度时，在建立子任务之前停止新图片调用，保留原图续答；实际返回超过剩余额度时保留成功操作、回执和产物描述符，标记 `image_adoption.unavailable`，不创建可发送图片来源、资产或 BLOB。
- 已知成功之后发生撤回、撤权、角色/实例变化或采用失败时，真实 `succeeded/committed/operation/receipt` 继续落账，材料永久撤销。无图片的撤销结果不创建空成功清单，重新授权不会自动采用；只有回执的前次调用也不会使后续合法调用丢失其成功回执。
- 群历史和生成图复用同一有界回溯预算；一次完整读取内缓存已验证结果，不能跨调用或绕过历史时间边界。未附图的文字答复也保留其视觉来源依赖。
- 提供方 generation 绑定包和后端配置版本，同配置正常重启复用；每次运行另设实例租约，旧对象、旧端口和失效实例不能借稳定 generation 继续执行。
- 未知后端结果不换调用编号重做；未知发送不自动重发。待发图片在正常重启后读取原产物及回执，迟到 ACK 仍校验原图文指纹。
- Image 的 SD 与 ComfyUI 配置位于独立 `native_v2` 区段，默认关闭。ComfyUI 对已提交的同一任务做有界只读等待，截止或结果未知时保留原 operation，不再次提交。
- V2 核心实现位于 `conversation/media/generated.py`、既有会话/模型/发送目录；宿主采用器位于 `astrbot_host/native_extensions/images.py`。本体没有新增根级业务文件或公共表迁移。

## 本片边界和下一步

当前公开编辑只接受同一原身份、角色及受众下由 Image 原生 owner 保存的 artifact。用户入站图片、Content 作品插图和其他来源的编辑引用需要后续宿主授权资源合同，不接受模型传入任意路径、URL 或 base64。

本批实际完成 Image 的原生执行主线，其他提供方按 [依赖审计](NATIVE_REFACTOR_DEPENDENCY_AUDIT_20260925.md)继续。Content 已有独立作品 owner 与原生协议适配器；下一片优先装配可信 owner/source/contributor 与 AccessPort，将固定作品版本、采用回执和作品撤回接入 V2 消费路径。必须让撤回继续影响模型上下文、缓存和待发内容，不能把工具返回正文当作永久可用副本。随后补跨来源图片编辑。真实后端和 QQ 客户端效果单独进行现场验收。

本片源码与最终隔离复验均已完成。隔离快照包含 V2 600 文件、Image 19 文件，终验后逐文件复核一致；后续源码变更需按影响重新验证。本记录证明合成后端与宿主下的原生执行链成立，真实 SD/ComfyUI 和 QQ 效果仍需现场验收。
