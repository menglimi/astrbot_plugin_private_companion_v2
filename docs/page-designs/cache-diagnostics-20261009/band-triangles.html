棱镜 · 三角形拼接两种解法

数据同前：命中 42.7 / 写入 18.3 / 普通 28.6 / 输出 10.4（占总量），界线 42.7% / 61% / 89.6%。三角化有两条路：少而大（一段一座峰）与多而小（拉链咬合、颜色按段切换）。

T1

山脊 · 一段一座峰

底边严格等比 · 倒影收尾

四段各变成一座三角峰，底边宽度 = 份额，峰高等同。面积即数据（底×高÷2 等比），山脊线把四段的相对体量直接"画"了出来。峰体渐变 + 发丝边缘，脚下压一层 16% 透明度的倒影，晶面感收尾。

命中 42.7% 写入 18.3% 普通 28.6% 输出 10.4%
AREA ∝ TOKENS · base = share · height = const
T2

拉链旗带 · 小三角咬合

颜色按段切换 · 虚线为数据界线

把带子拆成 26 枚小三角，上下交替咬合成一条拉链：中轴线贯穿，峰朝上、谷朝下。颜色仍严格按数据段切换（42.7% / 61% / 89.6% 三条虚线即界线），小三角让"边界"重新变得锋利可感。悬停任意三角会上浮。
