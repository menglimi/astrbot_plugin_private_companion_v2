保留设计稿的视觉结构，颜色、字号、间距和圆角跟随小屋主题。

- 筛选条可以直接切换当前角色的全部 V2、对话主链、插件任务，以及今日、7 日、30 日、累计和指定日期。
- 命中率总览使用圆环，显示 Provider 实报的缓存命中量 / 有可计算回执的输入量。

- 请求上下文的四个组成部分与完整请求使用同一批完整采集请求；拉链图说明与卡片都显示单次平均估算。
- 变化事件表最多显示 20 条，保留多变化标签、严重度、会话摘要、Provider 和前后指纹；展开行内快照可查看完整体量与估算。
- 缺少数据时显示等待状态或「—」。窄屏布局允许筛选换行、指标改为两列、表格横向滚动；表格与快照均可用键盘访问。

## 数据口径

真实请求估算包括参考材料文本、不含参考材料文本的消息估算、system 和工具文本。
媒体数量单列，不推算多模态载荷 Token。各项占比按完整采集请求计算，不把不同采集基数相加。
Token 构成中的输入分段来自缓存回执，未提供缓存字段的输入不计入构成。
事件仅显示 SHA-256 摘要前八位及体量，不显示提示词正文。

7／30 日命中率环比使用紧邻当前窗口之前的完整同长度窗口；按日期比较前一日；累计不提供环比。
稳定命中率是按输入 Token 加权的请求关联统计，不证明某一维度造成命中或失效。
