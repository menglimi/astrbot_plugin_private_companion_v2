Token 构成条带 · 五种视觉范式

不再是「圆角条 + 渐变」的换皮——五种范式各自换掉条带的表达方式本身。数据同前：命中 42.7 / 写入 18.3 / 普通 28.6 / 输出 10.4（占总量），界线在 42.7% / 61% / 89.6%。落码配色换主题 token。

范式 1

点阵 · 一百格账本

离散 · 可数 · 诚实

条带不再是连续色块，而是 100 个独立格，每格 = 1% 的本期 Token。占比是"数出来"的而不是"量出来"的——和你账本页的气质同源。悬停任意格会立起。

输入侧 89 格 · 缓存覆盖 68.1% 输出侧 10 格（±1 格为四舍五入）
范式 2

终端 · 字形即数据

维护页的原生语言

用等宽字形 █▓▒░ 直接"打印"构成：命中是实心 █，写入降一档 ▓，普通输入 ▒，输出 ░——明度本身就在编码层级，色只是辅助。自带扫描线与闪烁光标，和缓存诊断的排障语境严丝合缝。

CACHE://composition --period=currenthit 42.7% · write 18.3% · plain 28.6% · out 10.4%
范式 3

棱镜 · 斜切晶面链

几何签名 · 独一份的剪影

全页所有条形都是矩形——这条偏不：四段平行四边形晶面斜切咬合，像一条被打磨过的棱镜链。斜切方向统一 -18°，顶部内高光模拟玻璃折面。剪影即签名，一眼认出这是"构成卡"。

命中 42.7% 写入 18.3% 普通 28.6% 输出 10.4%
范式 4

霓虹负形 · 光只画界线

负空间编码 · 最反直觉

反转常规：段内几乎全黑（9% 透明度），只有三条数据界线是发光的霓虹管，两端带节点灯。深色主题里最省墨、最戏剧化——"构成不是涂出来的，是切出来的"。悬停无段可高亮，界线即焦点。

范式 5

波形 · 信号示波纹理

把构成画成一条被测信号

条带变成一段示波器信号：120 根微柱的振幅做纹理噪声，颜色在数据界线处切换。隐喻直给——缓存命中率本来就该像信号一样"越稳越好"。底部基线 + 等宽注记，仪器感自然长出来。
