这一版改了什么 / 为什么
  • 新增覆盖链（核心改动）。现状只用一行「当前：X · 上级：Y」交代来源，而真实合同是六级覆盖：default → installation → role → relationship → window → host_conversation。改成一条咬合链后，「值来自哪一层 / 上游被谁盖掉 / 下游谁能盖过它」三个问题一屏回答。
  • 目录行从「名称+圆点」升级为「名称+长度条+段数」。20 个任务里只有 6 个被改过，之前要逐个点进去才知道；现在长度条直接标出谁是空、谁写了长提示，段数标出有几个可编辑模板。
  • 编辑区加「内置默认」对照。现在默认值藏在最底下的折叠里；改为并排 / 差异双模式，改完能立刻看出偏离了什么。
  • 可编辑模板从下拉改成 chips。prompt_sections 里可编辑段可能有多个（模型任务提示 + 分段表达等），下拉一次只能看一个，chips 能同时看到哪段被改过。
  • 固定规则视图从「单个下拉」改成「左目录 + 右全文」。固定规则（editable=false 的 sections）是只读契约，条数不一，目录化后才知道有几条、当前看的是哪条。
  • 提示组成视图按装配顺序画成管线。5 层（角色指令 / 业务任务指令 / 模型任务提示 / 输出合同 / 能力指令）中只有第 3 层可编辑，管线里高亮这一层，其余层标「运行端提供」。
  • 状态筛选补齐「内置默认」。现状只有「全部 / 已自定义」，想知道哪些还没动过只能靠排除。
  • 排版再收敛（本轮）。目录封顶 540px 内部滚动——20 条全展开会把整行拉到一千多像素，右栏只有六百多，那一大片空白就是「乱」的直接来源；两栏之间加一条发丝线分区，不再靠留白猜边界；编辑区与固定规则区统一到 320px，两块底部对齐；覆盖链「当前生效」从压在节点底部的绝对定位挪到右上角胶囊，不再和两行文字抢位置；条件说明与动态字段并成一行。
  • 使用体验（本轮）。输入时不再整块重绘，只刷新字数条与按钮，光标和滚动位置都不丢；保存 / 恢复继承值真实生效（写入草稿、长度条、状态与覆盖链）并给一次 toast；未保存在页头计数、在目录行标「未保存」；快捷键 / 定位搜索、↑↓ 换任务、Esc 清空、Ctrl+S 保存；筛选无结果时给一键清除；窄屏两栏改单栏、覆盖链改两列网格。
  • 刻意没做：不做「批量编辑 / 导入导出 / 版本历史」——后端 savePrompt 一次只提交一个 kind 且靠 edit_token 做冲突检测，批量能力需要先有后端合同；不做提示词效果预览——会引入真实请求正文，与本页「不展示任何请求正文」的隐私边界冲突。
