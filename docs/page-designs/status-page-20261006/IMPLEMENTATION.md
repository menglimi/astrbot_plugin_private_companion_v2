# 状态子页面配置区域实施

日期：2026-10-07。对应本目录的骨架图与 01–12 设计图，已接入唯一公开页「陪伴小屋」。

状态看板提供能量、健康、饥饿、睡眠、生理期、心情、忙碌和位置八项详情；看板下方提供 QQ 状态、日程配置、天气、时间与日期四个醒目入口。每日巡视位于「治理与维护 → 每日巡视」，不再列为状态。各子页采用头部、当前情况、分组配置、相关设置与底部操作条。

## 配置与操作

- 「状态功能与首页展示」收进外层「状态」标题旁的设置按钮，以原生弹窗编辑；支持键盘操作、关闭后返回原详情与恢复按钮焦点，未保存修改和结果未确认的请求会阻止关闭。
- 八项状态各有功能开关与首页展示开关。健康、饥饿、睡眠、生理期、忙碌另有「仅特殊值」：仅生病或不适、饥饿、失眠或睡不好、经期、忙碌时展示；正常、否定、未知和未记录的值隐藏。
- 功能开关通过真实状态配置保存。关闭对应模拟时，提示词要求该字段为空，读取投影隐藏该项与临时感受，保留已有存储记录和展示偏好。睡眠感受开关不取消真实作息，忙碌感受开关不关闭日程和回复闸门。
- 能量：表达强度滑块与精力引导；当前能量只读，周期精力偏移跳到生理期。
- 健康、饥饿：模拟开关与表达引导各占一组，分别保存自己的字段。
- 睡眠：显示共享作息与真实执行回执；作息编辑跳到日记与生活，回复行为跳到开口闸门。
- 生理期：周期方案与阶段表达共用一个草稿；通用设置、不适模拟、阶段时长分组；阶段偏移、氛围词、引导与整体偏好分别编辑；周期校准仍是独立命令。
- 心情：开关、更新概率、单轮幅度与回归半衰期。
- 忙碌、位置：只读。忙碌提供日程与回复闸门跳转，位置显示角色模拟的来源说明。
- 日程与规划：角色日程、运行模式、编排范围、年度日历与生活偏好分组；保留计划的创建、修订、例外、提醒与取消入口。
- 天气：感知开关、角色地点、成对坐标、成对预警区域与信息时效；提供「数据源与和风凭据」入口，直接定位感知页。
- 时间与日期：当地时间、日期与时区合并显示，可保存小屋与日程时区；日期开关、农历、节假日及节气直接打开感知页的现有配置。
- 每日巡视：在维护页编辑开关、巡视时刻与保留天数步进器，复用原保存端点与范围。
- QQ 展示：开关、刷新间隔与平台回执，确认未知不自动重放。

可编辑子页直接展示草稿表单；保存仍使用原 `state/command`、编辑令牌和操作键。取消与重置恢复已保存值，未保存修改显示提示，并阻止在未处理草稿时切换子页、导航、家具或关闭浏览器。未知保存结果保留原请求用于核对，版本冲突支持读取当前版本后继续编辑。

## 与示意图的实际数据差异

后端 `PhysicalSettingsOwner` 将 QQ 展示以外的状态配置按人格共享，因此心情与巡视的范围标签显示当前人格；没有改动后端归属。巡视保留天数使用实际支持的 **3–180 天**。睡眠、忙碌与位置不提供没有保存接口的控件。没有观测或诊断数据时显示尚无记录或自动选择，不填入示例百分比、更新时间、巡视成功记录或天气数据源。

## 代码与验证

配置字段与分组在 `pages/陪伴小屋/state-maintenance.js`；草稿与保存在 `state-editor.js`；当前情况、相关入口与生命周期在 `state-page.js`；配置区域样式为 `state-config.css`。`app.js` 提供标题设置按钮、草稿导航检查与巡视维护路由；`home-sidebar.js` 使用保存后的开关和条件筛选首页状态；`home.css` 按实际网格列约束状态悬浮说明，避免筛选后在窄屏溢出。

天气感知区新增 `weather-source-page.js` 与 `weather-source.css`，可选择自动、和风或 Open-Meteo，配置专属 API Host、JWT/API Key 与 1–120 分钟缓存刷新间隔。地点、信息时效、天气问候、突变采样、去重窗口、官方预警开关、轮询间隔和最低级别均留在该区的真实编辑器中。凭据保存到宿主 `weather` 配置组，不进入角色配置；GET 不回显凭据，输入留空保留现有值。环境变量自动签名 JWT 保持兼容，直接 JWT 过期后需更新。未知保存结果只重新读取核对，不自动重放凭据请求。

宿主 `weather_settings.py` 统一源选择与有界缓存；保存后立即替换运行中日程、天气问候、突变和官方预警的端口，旧缓存随端口更换失效。重启时单目标与多目标组装使用同一保存配置。`host-options/weather` 复用宿主 Dashboard 身份校验、冲突令牌与配置保存接口，GET 与 POST 都只注册一次。手机端感知配置容器设置 `min-width:0`，防止页签撑大网格而裁切实际表单。

最小检查：状态字段、草稿、闸门、日历与导航测试；状态投影、配置、心情、身体和维护的定向领域测试。浏览器验收工具 `tools/check_state_config.cjs` 使用合成宿主，覆盖 1366、390、320 像素宽度的状态入口、十二个详情、设置弹窗和维护巡视页；验证八项功能与展示开关、五类条件、最小保存补丁、重置与取消、关闭保护、焦点返回、刷新后恢复原编辑区域、日期导航、阶段切换、周期校准、天气与 QQ 设置和诊断、原请求恢复、冲突重基、回执焦点保持、角色与会话隔离、权限撤销。`tools/check_state_page.cjs` 的默认入口复用同一验收流程。最终交付包必须从当前源码构建，再运行这些检查及宿主加载、停止和路由注销检查。
