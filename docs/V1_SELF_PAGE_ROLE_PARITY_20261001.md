# V1 世界知识与 V2 角色档案对照

日期：2026-10-01。对照对象为 V1 `pages/陪伴面板/index.html`、`pages/陪伴面板/app.js` 与 V2「陪伴小屋」自我、关系与权限、产出工作区。只检查源码，没有读取、迁移或修改 V1 用户资料。

## V1 的实际范围

V1「世界知识」不是单独的世界书导入页，而是一个角色背景工作台，包含以下章节：

- **角色资料**：姓名、种族、生日、性别、外貌识别点、发型、瞳色、服饰、职业/身份、性格、目标、爱好、禁忌、关键设定和补充信息；另有特殊图像身份线索。
- **角色衣柜**：整体穿衣倾向、具体衣物及图片识别，并可单独控制衣柜是否写入提示。
- **世界设定**：世界、时代、基调、规则、活动场景、人物/组织关系网及补充。
- **引用资料**：世界书、AstrBot 知识库/文档和知识图片；可勾选 `kb:<id>` / `doc:<kb>:<doc>` 来源，后台会按角色资料和世界设定检索片段，通常最多取 18 条、3200 字；检索无命中时会回退到文档代表性取样。
- **关系资料**：默认称呼、用户特征、角色关系和互动方式，按关系范围管理。
- **人格导入草稿**：读取 AstrBot 当前主回复人格，由模型抽取角色、世界或用户范围；页面先呈现草稿和来源，再由用户选择填入空白项或二次确认覆盖。抽取不会自动保存工作台，也不会修改 AstrBot 人格。

页面还提供旧版整段文字模式、结构化模式、字段帮助和角色预设。V1 把这些能力放在同一页签下，但它们并非同一数据归属：人格、用户关系、衣柜和资料来源的消费者不同。

## V2 的归属与本轮补充

V2 按领域把同类编辑放到各自唯一的公开入口：

| V1 章节 | V2 入口 | 处理方式 |
|---|---|---|
| 角色身份、外貌、性格、目标、边界、世界蓝图、平台称呼 | 自我 · 角色档案 | 角色级共享；新对话封存时进入该角色提示 |
| 衣柜 | 产出 · 衣柜 | 保留具体衣物及生成/图像消费者，不复制一套自我页字段 |
| 世界书与知识库 | 自我 · 世界知识 | 管 V2 独立导入来源；来源进入 V2 知识目录后，当前角色档案整理可检索其中的全局资料 |
| 用户关系与互动资料 | 关系与权限、关系资料 | 按当前用户和私聊范围管理，不混入角色自身档案 |
| AstrBot 主回复人格 | 自我 · 人格底稿 | 宿主原文只读，编辑版本另存，不写回宿主人格 |

本轮新增结构化资料：独立生日字段、自称与代词、情绪表达、社交距离、典型反应、原创口吻示例和标志性表达。它们从编辑器、封存快照一直进入角色稳定档案提示；口吻示例用来校准表达，不作为要照抄的台词或场景事实。顶部速览新增口吻入口，点选后跳到相应编辑分区。资料计数按实际有值的字段计算，不再把“某一组有任意一个字段”显示成整组完成。

旧快照缺少本轮新增键时，重放会把这些新增项补为空值；既有角色资料正文和原始字段保持不变。原 `age` 字段曾兼用“生日/年龄感”，故保留旧字段值和提示语义，并新增独立生日字段，不擅自把含义不明的旧文本搬到新字段。

## 角色整理流程

V1 的人格导入是「读原文 → 生成草稿 → 预览和手工编辑 → 选择填入空白项或确认覆盖」，不会自动保存，也不会写 AstrBot 人格。V2 保留这条确认边界，并把输入扩展为三类：只读的当前人格、操作者确认补充的事实、当前角色可用的 V2 全局世界资料。

世界资料只取 V2 已导入目录中当前角色可见且不带窗口边界的条目，按人格和补充设定检索，最多 18 条、合计 12,000 字。页面展开显示实际参与本次整理的来源和正文；没有资料时可直接跳到「世界知识」配置。群聊专属条目与成员线索不进入稳定档案；用户关系仍留在关系工作区，具体衣物仍归衣柜。

未知生日、身份经历、现实事实或亲密承诺继续留空；来源材料只作为整理参考。输出字段可编辑，只有操作者选择并确认后才写入角色档案。
