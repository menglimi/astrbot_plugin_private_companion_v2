# 主动新闻分享与私聊灵感清单

2026-10-08。本轮针对主动新闻像机械播报、缺少分段、正文附带来源页脚的问题，按用户提出的每个私聊窗口维护主动灵感清单的方向实现。

## 表达与分段

- 用提示词引导角色从一个具体亮点出发，自然表达好奇、惊喜和分享欲，保留原人格的年龄感、称呼及关系距离。严肃消息采用相应语气，不固定兴奋台词、幼儿口吻或段数。
- 新闻字数约束作用于总正文，不再要求压成一句。规则分段提示保留对应停顿；模型分段提示使用现有消息边界标记，并适配少标点、换行清理。
- 沿用生成时封存的表达配置。分段关闭时仍发送一条消息，可以保留正文段落；不会自动打开分段。
- 主动路径取消程序追加的“来源 / 原文”页脚。来源、发布日期、标题、摘要及规范化原链接保存在原主动联系记录中，并绑定已完成本地操作的参数指纹。

## 每个私聊窗口的清单

- `ProactiveInspirations` 从现有主动联系记录及背景投递回执生成清单，不新建重复数据表。按当前完整窗口上下文隔离，包括账号、会话、角色和受众。
- 清单保留主动目的、灵感摘要、已确认发出的正文、分享时间及对应新闻出处。记录只代表已确认投递，不证明用户已读或新闻已获独立核实。
- 普通聊天的背景历史只包含已发送正文，不附出处字段。来源、原文、链接等追问触发清单读取，给模型多个候选记录，提示根据用户指代和标题匹配，不能默认取最新一条。
- 追问识别目前沿用近期新闻查询的轻量文本入口；明确出处表达可读取清单，表达匹配由提示词处理。合成测试验证材料与流程，不代表所有含蓄问法的语义召回率或真实模型文风已通过实测。
- 每轮最多展示最近 8 条可用记录、8192 字上下文，原记录仍保存在已有日志中。每条可聚合原分段配置允许的最多 64 个已确认消息段，不截成 8 段。每个回合封存的清单仅保存原投递引用，不复制正文或链接。
- 追问回合的引用保存在原对话批次中。生成校验、发送前及历史依赖读取都重新检查，包括重启后和未启用语义召回的历史读取。
- 结果未知的发送不视作说过；部分投递仅展示已确认的气泡。迟到的可信送达回执可使记录进入清单，不重发原消息。

## 来源边界

- 追问回忆的是原分享出处，不重新抓取另一条资讯替代。新闻源的时效租约及轮询开关约束新的事实引用和发送，不自动抹去过去确认分享的出处。
- 历史出处校验只读取来源元数据，不返回原来源正文、不续租。当前身份授权、精确来源版本、原受众、内容指纹及撤销仍需通过。
- 原封存出处被篡改、来源被撤销、回执失效或上下文变化时，新清单过滤该条；已使用该条的回合重新校验失败，阻止派生回复。
- 使用 V2 独立数据与本地合成夹具；未读取、迁移或修改 V1 用户数据，未调用真实新闻端口、在线模型或平台发送。

## 验证与交付

- 定向回归覆盖重启与过期后追问、普通聊天不附出处、多个分享引用较早文章、跨窗口隔离、未知与部分投递、迟到回执、封存篡改及生成期间撤销。
- 定向检查同时发现并补齐宿主调度 `slots_for` 路径缺失的 `json` 导入，避免处理消息时进入故障状态。
- 小屋继续使用唯一公开页“陪伴小屋”，分享资讯说明与新行为一致，无新增开关或公开页面。
- 当前源码同步小屋、构建新交付包后，对新解包代码统一运行相关 Python / 页面回归及宿主加载、停机与路由注销检查。实际计数及结果记录在本轮交付目录的 `PACKAGE-REGRESSION.md` 和 `PACKAGE-REGRESSION.json`；此前交付包结果不作为本轮证据。
- 打包脚本明确排除录制 RSS 原文夹具。端到端回归将仓库中该样本补到隔离解包测试目录，校验其哈希，安装包及包内代码保持不变。
- 七个可选提供方的整套打包曾因相邻 Screen 插件缺少 `astrbot_version` 元数据而阻断。本轮交付为独立 V2 本体包，提供方未修改。
