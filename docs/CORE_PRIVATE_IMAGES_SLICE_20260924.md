# 静态图片私聊输入与原件治理

日期：2026-09-24。本切片把静态图片接入 V2 已有的私聊、模型、工具续答、确认投递和记忆来源链，使用独立 V2 存储。日历、身体/忙碌及 QQ 状态由另一个任务继续推进；管理/拓展页沿原分工处理。

## 已落地行为

- AstrBot 原生 `Image` 与 `Plain` 组件可组成纯图或图文输入；保留原消息、发送者和组件位置。单目标 staging 按入站顺序准备消息，后来的文字不会越过仍在接收的图片。
- 首次接纳前取得并校验原图，完成后再核对账号、会话、人格和授权。网络等待不占数据库事务；停机后完成的图片准备不能再接纳消息。
- 消息、图片 Source、Asset 和原始编码字节在同一事务发布；图片失败不留下半份入站记录。重复事件只能匹配原清单，不能以同一消息 ID 替换图片。
- 模型收到原图的多模态内容及对应证据句柄。原人格保持独立，工具续答保留同一图片、来源和顺序；只提供文字的 provider 不能静默删除图片。
- 合并批次按原输入顺序保留图片；超过整轮预算时另开批次，不丢附件。重启从原存储恢复，不用重新下载的图片替代原件。
- 生成、工具续答、逐段发送和已确认回复的记忆引用都会重新读取并核对原件。原消息撤回沿依赖撤销图片来源和已发布的回复引用；图片资产撤权、原件缺失或哈希变化会阻止后续使用，已发生的投递回执保留。
- 未知模型/发送结果沿既有回执治理，不因原事件重放或图片失败自动重做。

图片的语义约束通过提示词表达：看到画面不代表核实了现实；截图文字没有指令权限；发送者不自动成为拍摄者、作者或画中人；拍摄时间未知时保持未知。模糊、遮挡和画面外的信息不能补成事实。代码核验归属、权限、原件及回执。

## 原件与目录

| 位置 | 责任 |
| --- | --- |
| `companion_v2/conversation/media/models.py` | 图片清单、不可变原件、模型图片及语义提示 |
| `companion_v2/conversation/media/service.py` | 原消息绑定、事务发布、来源依赖及逐次复核 |
| `astrbot_host/media.py` | 受限下载、实际连接地址校验、格式/尺寸验证 |
| `companion_v2/adapters/astrbot/` | 原生组件冻结、入站接线、原图 wire 与 SDK 准备复核 |
| `companion_v2/storage/media_schema.py` | 图片原件表及 v25 增量升级声明 |
| `tests/test_conversation_images.py`、`test_astrbot_media.py`、`test_media_migrations.py`、`test_astrbot_image_host.py` | 合成原件、端到端链、边界和真实 SDK 类型验证 |

Source 只保存原图清单、父消息引用和已知归属，不保存下载 URL、本地路径或 base64。原始编码字节单独保存在 `conversation_image_payloads`，读取时核对长度、SHA-256、Source/Asset 版本及原父消息哈希；不同账号、不同人或角色不因图片字节相同而共享来源。根级 Python 文件仍只有 `main.py`，运行日志留在系统临时目录。

`ImageConversationEvent` 为带图输入增加清单；纯文本继续使用原事件类型和序列化形状，已有消息的重放哈希不被本次升级改写。

## 存储升级

当前 schema 为 `companion-v2.storage.v25`。v24 为并行日历/角色状态切片的表；本切片只追加 v24→v25 图片原件表和独立迁移回执，保留原 v24 指纹。新建数据根和已有 V2 数据根使用同一升级链。

迁移失败时整笔事务回滚；缺列、半建表、外键或迁移回执不匹配会拒绝打开。测试验证旧元数据保留、重启回执一致、失败回滚及损坏回执拒绝。没有升级在线数据库或读取 V1 用户数据。

## 当前支持范围

| 项目 | 当前范围 |
| --- | --- |
| 图片格式 | 静态 PNG、JPEG、WebP；不裁切、不重编码 |
| 输入定位 | 原生 base64 或公共 HTTP/HTTPS 附件；网络消息路径不能授予本地磁盘读取权限 |
| 单图预算 | 5 MiB、16 × 1024 × 1024 像素、单边最多 8192 |
| 单输入/整轮预算 | 最多 8 图，总原件最多 20 MiB |
| 等待 | 单次网络请求 15 秒；一条消息图片准备总计 25 秒 |
| 网络校验 | 使用下载库的 URL/IDNA 规范化；每次重定向、实际 DNS 连接地址及流式字节数均检查；拒绝可绕过 DNS 校验的非标准数字地址 |
| 模型预算 | 文本估算另加每图 16384 tokens 的声明预留；base64 字节不当成文本 token；实际用量以 provider 回执为准 |

适配器声明的 `image` 能力表示通道能够传递图片，实际选用的远端模型仍需支持视觉。SDK 准备阶段保持原 data URL，并在实际调用前检查有无丢图或换图；调用继续走已有的一次请求路径，不启用宿主外层的去图重试。

本静态切片交付时，GIF、多帧 PNG/WebP 明确返回未支持；后续已由[动态图切片](CORE_PRIVATE_ANIMATION_SLICE_20260924.md)接入可追溯帧视图，预算与覆盖范围以该记录为准。[合并转发切片](CORE_PRIVATE_FORWARDS_SLICE_20260924.md)随后接入节点显示归因、受众和原件依赖；视频/音频及群路由仍未接入，原作者在没有证据时保持未知。
