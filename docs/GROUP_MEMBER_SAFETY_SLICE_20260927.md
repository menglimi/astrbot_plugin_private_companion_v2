# T08 群成员风控切片（2026-09-27）

## 实现范围

T08 已完成首版源码接线，按定稿方案分为“规则命中、每日反思证据、人工审阅”三段：

- `companion_v2/memory/group/hits.py` 提供四类确定性命中：仿冒机器人/管理员/客服、验证码/支付/转账/收款等敏感词、高频重复消息、`@` 轰炸。命中只保存证据，不建立成员画像。
- 群入站接纳和 Bot 出站派发分别记录命中，记录归属复用群记忆 owner；证据写入失败不会阻断正常接纳或发送。
- 确定性规则所需的词表、文本上限、重复窗口/阈值、`@` 阈值和反思证据上限集中在 `GroupSafetyPolicy`；调用方可注入策略，默认策略只提供兼容默认值。
- 群每日反思在现有反思材料之外注入当前群 owner、指定 `[start, end)` 时间窗内的有限命中记录。提示词明确命中是证据而非事实，建议必须引用 `hit_id`，禁止建立成员画像、禁言、封禁或修改权限。
- 回复阶段不由程序硬编码称呼；Bot 结合当前语境自行判断是否自然、是否可能造成误认或冒犯，拿不准时使用中性表达。每日反思会在有原始来源时复核称呼使用，证据不足不猜测，一次称呼不会自动沉淀为长期偏好。
- 既有群记忆管理入口增加 `/safety` 查询和 `/safety/review` 审阅。查询支持成员、审阅状态和游标分页；审阅只写人工回执，不改变成员权限。`operation_key` 对同一群 archive 幂等，跨命中复用会返回冲突。
- V2 存储由 v40 升至 v41，新增 `group_member_safety_hits` 表及迁移记录。初始化新数据根和既有 v40 数据根均执行迁移；不读取或迁移 V1 用户数据。

## 边界

风控记录按完整群 archive 隔离，包含 installation、platform、Bot、account、group、session 和 role 绑定。非群 scope 不注入群风控材料。查询和审阅均要求现行管理权限；证据损坏时降级为不可用标记，不影响其它记录读取。
