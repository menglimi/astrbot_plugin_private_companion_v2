# V2 游戏共处与自由玩法复核

日期：2026-10-01

## 复核结论

V2 已接入井字棋、五子棋、中国象棋、掷骰竞分、二十一点、海龟汤和你画我猜。游戏工具可用时，回复提示强调共同在场与动作互动；掷骰保留通过操作影响结果的空间。

## 本批改动

- 有授权的 `game.*` 工具进入目录时，为回复加入共处式游戏提示：少做规则播报，接住玩家反应，并依对方态度决定继续、承认或收手。玩家要求公平时按普通操作执行。
- 掷骰仍只有普通的 `game.pig_dice.roll` 操作，可选择桌面直掷或沿骰盅边缘送出；首个点数为 1 时，后者会让骰子再滚一次。前后点数写入游戏事件，状态按最终点数结算并支持跨重启回放。
- 游戏提示鼓励角色通过动作留下轻微痕迹，让互动自然发展；对局能力仍遵守 Game 提供方的授权与幂等回执。
- 定向验收：新交付包哈希与语法校验、宿主停机和路由注销检查，以及掷骰、身份/记忆与提示共 7 项测试均通过。

## 边界

掷骰边缘手法先做成完整垂直切片；其他游戏仍由角色通过临时叙事规则增加弹性，尚无对应的局面修改动作。浏览器房间和多人席位也不属于本批原生聊天游戏实现。
