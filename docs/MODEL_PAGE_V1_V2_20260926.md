# 模型页：V1 到 V2 的接入边界

V1「模型配置」将任务 Provider、快速/精准模式、搜索筛选、替换策略、语音合成和生图后端集中展示。V2 保留任务分组与搜索筛选的操作方式，但以已注册的 V2 任务和 Provider 为准，不读取或迁移 V1 用户配置。

2026-09-27 收尾更新：功能模型、语音模型、生图模型三个页签均已接入真实受控 API，本表按当前源码修订。

| V1 区域 | V2 当前入口 | 接入状态 |
| --- | --- | --- |
| 任务模型分组、搜索与已配置筛选 | 模型与连接 / E2 | 已接入注册任务的当前配置、来源和编辑状态 |
| 每项任务的主 Provider、备用 Provider、Token 上限 | 模型与连接 / E2 | 已接入 V2 已注册任务；当前宿主只注册一个共享 Provider，更多候选需要独立适配器 |
| 任务附加提示词 | 模型与连接 / E2 | 已接入；与角色人格分离，允许空附加提示词 |
| 单项超时 | 模型与连接 / E2 | 已接入；逐任务 1–600 秒，输出上限仍受 Provider 能力封顶 |
| 快速/精准配置 | 模型与连接 / E2 | 已接入适配版：快速配置按任务分组统一指派主 Provider 并逐项保存；精准配置逐任务编辑全部字段。两个入口共享同一份逐任务配置，没有 V1 式快速/精准两套运行模式 |
| 时段和关键词替换 | 模型与连接 / E2 | 已接入：关键词规则（匹配方式、条件、优先级、模型覆盖、可选时段窗、时区、跨午夜）写入任务 `replacement_rules`；拒答替代写 `fallback_on_refusal`；作用范围写 `replacement_scope`。高价时段替代以通用时段规则实现，不再绑定 DeepSeek 专属配置键 |
| 逐项在线测试与测试全部 | 模型与连接 / E2 | 已接入：逐 Provider 连通探测（`/model/test`）与态势图多选批量测试；只验证 Provider 可达，不提交真实任务 |
| 语音合成 | 模型与连接 / 语音模型 | 已接入：读取 AstrBot 已加载 TTS Provider，按语种绑定、合成超时与合成测试（`/model/voice*`）；触发时机、频控与发送形态仍在「表达 / 语音」 |
| 生图后端 | 模型与连接 / 生图模型 | 已接入 Native 提供方开关：管理 V2 对 Native 生图动作（文生图/改图）的启停与注册检查（`/model/image*`）；扩展凭据与执行由各提供方扩展管理，V1 多后端优先级队列未迁移 |

当前页面只通过已登录 Dashboard 的受控 API 读取或修改所选私聊对象及角色的 V2 配置。保存采用版本令牌和稳定操作键；网络结果不明确时只重试原操作。配置在下一次任务启动时采用，已开始的任务保留原计划。V1 的 44 项 E2 配置需要逐项判定语义后才能标为完成，不能按字段名批量迁移。
