# 会话模型与 Gemini 回复链路修复

普通回复和主动联系正文在没有显式任务路由时，采用对应 AstrBot 会话的模型。日历规划、记忆整理等维护任务继续采用插件默认模型。任务显式设置及替换规则保留原有优先级；工具续答保留首次选定的模型。

模型路由现在分别保存原配置快照和有效路由投影。会话模型选择不再改写配置校验快照，避免没有保存任何配置时误报 `configuration_revision_conflict`。真实配置变化仍会拒绝过时计划。

Google GenAI 适配器接受普通文字输入、原生图片及 MP4，并保持原角色校验、媒体边界和发送前的任务复核。工具调用返回的 continuation signature 只在适配器内暂存，按原事件、角色、模型、配置与原工具参数回传；不会进入工具参数、提示词正文、历史正本或开发日志，完成正文后释放。同一适配器也支持管理页的固定文字连接测试。

`conversation.reply` 的模型调用及工具续答属于主链，不检查或消耗插件模型预算；维护页的插件预算统计也排除这些调用。后台模型任务仍使用原预算合同。

群历史验证接受已封存的熟人卡及群关系快照，按原上下文验证；已确认的 Bot 回复重新可用于后续群对话。撤回、授权撤销及来源失效继续隐藏派生正文并保留原投递回执。

新配置默认关闭正文内容清理。分段清理测试显式配置清理开关、范围、词和规则，验证启用后的实际投递；普通配置保留正文标点，仅移除首尾空白行。

定向回归位于 `test_host_model_defaults.py`、`test_gemini_native_video.py`、`test_conversation_messages.py`、`test_role_tool_loop.py`、`test_group_conversation_context.py` 和 `test_incremental_reply_delivery.py`。交付验收从新包解包运行，使用 AstrBot 自带 Python 和临时 SDK 数据根。真实私聊成功须以新调用和实际投递回执确认，连接测试与合成平台回执不代替用户收到消息的证据。
