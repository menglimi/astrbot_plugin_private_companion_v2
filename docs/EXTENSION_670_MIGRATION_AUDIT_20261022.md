Game、Together、Live 的转换只接受当前原生拓展 schema 中类型、选项及范围匹配的字段。已在新版配置页改过的非默认值保留；试算与保存仅锁定相关字段，其他配置页改动不会让整份计划失效。损坏的可选拓展配置会使升级记录保持“部分完成”，但不会阻止其他来源先迁移。Live 的旧字段别名与运行时共用同一映射。

Content 与 Memory 的独立配置优先于本体缺省来源，每个目标分组只生成一次写入；已保存的新版显式设置继续保留。模型需通过新版实际消费入口的校验。定向测试验证了记忆摘要模型及备用路线、创作模型、检索预算在其他窗口中实际生效，没有模型调用或消息发送。

Memory 还修复了超时参数保存后不完全生效的问题：旧配置允许模型等待 240 秒，新版反思任务外层原先固定 180 秒。现在任务截止时间覆盖配置的主备模型等待时间与本地持久化开销，正常的恢复、防重复和撤销检查继续生效。回归验证检查了实际提交的任务截止时间。

Reality 的同义偏好包括摄像头主动频率参数、家居请求超时、健康数据有效期，以及手机会话、位置、遥测、活动和地图缓存的有效期/超时；迁移这些参数不会开启对应服务。所有其余来源字段均有核对说明，日志与试算不携带其凭据。旧配置同时存在平铺键和分组键时同步更新，保存失败恢复原配置；视觉模型在试算及保存前均核对当前能力。

此轮不迁移旧拓展的房间会话、媒体、创作项目及设备观察数据。原有 Content 项目数据和拓展会话/媒体在目录中分别列为外部保留或暂缓，不能因配置项已导入就宣称资料也已迁移。
