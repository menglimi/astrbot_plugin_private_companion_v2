# 重要日期主动问候（2026-09-26）

V2 可按目标私聊配置的 `quiet_timezone` 在当天生成一次日期问候候选。`proactive.contact.date_checkin_enabled` 默认关闭，且需同时开启总联系与 `automatic_enabled`。候选进入原对话的免打扰、额度、模型发送/跳过与投递链；没有最近已完成的原私聊时不主动建立新目标。

`date_checkin_time` 是当地 `HH:MM` 时间，触发窗口为 45 分钟，过期不补发。`important_dates` 是最多 32 项的 JSON 字符串，可在安装、角色、关系或私聊层配置：

```json
[{"month":9,"day":21,"label":"共同纪念日"}]
```

旧格式保持逐年公历日期；农历日期须显式声明 `calendar`，例如：

```json
[{"calendar":"lunar","month":8,"day":15,"label":"农历纪念日"}]
```

闰月单独配置 `"leap_month":true`，默认只匹配非闰月。同一天公历与农历的多个标签共享一次机会；不存在的农历月日当年跳过，历法提供方不可用时也不猜测。安装依赖 `lunarcalendar`；匹配使用配置的 `quiet_timezone` 下的当地日期，不从对话推断生日、纪念日或双方关系。公历 2 月 29 日只在闰年触发。内置固定公历节日目前只有元旦、劳动节和国庆节；节日名称不证明实际放假。配置、时区或原对话在生成/投递期间变化时，旧候选失效；已生成的任务跨重启不重复。

本切片不处理自动发现重要日期、真实放假数据或节气问候。`tests/test_proactive_date_events.py` 以合成私聊、模型和平台回执验证候选、去重与失效；尚未验收真实模型及 QQ 效果。
