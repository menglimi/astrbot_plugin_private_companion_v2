日期：2026-09-25。范围：新撤回桥的公共宿主入口、AstrBot 4.27.2 SDK 转换和插件生命周期。

本次只新增测试与本记录，没有修改生产实现。

## 覆盖

- SDK 给 notice 生成的 UUID 不参与原消息定位；原消息 ID 来自 `raw_message`，接受合法负数 ID。
- 私聊与群聊撤回、重复通知、通知先于消息、两类控制器重启后的撤回标记。
- 同一平台下两个 Bot 账号、私聊与群聊、不同群之间的同消息 ID 隔离。
- 管理员代撤回保留原作者身份；群 `user_id_group_id` 会话与原始 `message_obj.session_id` 对齐。
- 原人格和当前会话变更后仍撤回原始输入，撤回入口不依赖当前人格查询。
- 字段不一致、未配置群、平台替换、账号断开不会写入撤回标记或撤销来源。
- 人格解析期间、模型生成期间、第一段已发出而 ACK 尚未返回期间的撤回。
- 已确认 ACK 和 unknown 回执保持原状态；剩余分段取消；重启不重发未知结果。
- 群 Bot 已确认回复被撤回后，历史正文不可用而实际发送回执保留。
- 撤回已引用的原文会撤销引用来源，保留引用者自身输入；提前撤回的原文不能通过后续引用进入模型或数据库。
- 非撤回 notice 不被普通消息入口接管，原生撤回观察器保留通知供其他插件处理。
- 独立 SDK 子进程直接运行 `AiocqhttpAdapter.convert_message()` 和 `create_event()`，再调用真实 `main.py` 观察与消息入口，覆盖私聊、管理员群撤回、独立会话、重复、乱序、停机及路由清理。

## 文件

- `tests/test_astrbot_recall_host.py`：17 个宿主用例及 1 个 SDK 子进程入口用例。
- `tests/recall_host_support.py`：按已核实 SDK 字段构造通知，保留固定平台和 client 身份。
- `tests/recall_entry_process.py`：真实 SDK 转换和插件加载、注销流程，平台与模型使用进程内假实现。

三个新增 Python 文件均检查了 UTF-8、无 BOM、LF、末尾换行与语法。后续生产实现若调整来源传播，应复验受影响宿主用例和该入口用例；本记录不替代真实 OneBot 连接的现场验收。
