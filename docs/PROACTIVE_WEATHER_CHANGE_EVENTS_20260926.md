# 角色所在地天气变化主动联系（2026-09-26）

V2 已接通默认关闭的天气变化主动联系。管理员先配置 `planning_weather_location`，再开启 `proactive.contact.weather_change_enabled`；还需开启总联系与自动联系。正常取样间隔为一小时；抓取失败可在五分钟后重试。链路只比较同一角色所在地、间隔不超过六小时的两次新鲜 Open-Meteo 当前观测。更换地点后的第一次观测只建立新基线，不会拿旧地点的天气作比较。

从晴/多云到雨、雪、雷等天气类别变化，气温差至少 6°C，或风速从低于 20 km/h 升至至少 35 km/h，才生成环境类候选。事件有三小时冷却和 45 分钟窗口，仍需经过原私聊的免打扰、额度、模型发送/跳过、来源复核与投递链；过期、地点变化、配置关闭或观测失效都会阻止旧候选继续发送。抓取失败会稍后重试，不将失败写成天气变化。

这只是角色所在地两次当前观测的差异，不是用户所在地天气、未来预报或官方预警。官方预警由独立的[和风天气链路](OFFICIAL_WEATHER_ALERT_SOURCE_20260926.md)提供。合成测试覆盖基线、显著变化、地点切换、过期观测、关闭配置与跨重启去重；真实 Open-Meteo、在线模型及 QQ 投递尚未现场验收。
