# V1 用户 vs V2 用户：内容差多少（2026-09-30）

问法：「对比 v2 的用户和 v1 的用户，看看差了多少内容」。
口径：**用户能看见、能设置、能玩到的东西**为分母——配置项、页面/面板、内容型体验三类。
数据来源：V1 仓库现状（`_conf_schema.json`、`pages/`）、V2 账本 `docs/V1_V2_CONFIG_VERIFIED_20260927.csv`（1010 行）、
V2 账本 `docs/V2_CONFIG_SURFACE_20260928.csv`（604 字段）、V2 页面与代码实测。**不采信文档自评。**

---

## 四、内容型体验：V1 用户熟悉、V2 用户今天没有的

1. **Token / 花费用量**：V1 有独立统计页；V2 只有软限额设置，看不到"用了多少"。
2. **独立排障面板**：V1 有排障页（最近错误、调用回看、自检）；V2 只有回复链的局部诊断，诊断域的答疑/自检/修复建议**没有页面入口**。
3. **合并转发投递**：V1 能把分段回复合并成一条转发发出；V2 只能逐条发。
4. **群"高密度降载"**：V1 有"窗口内刷屏就自动收口"的整套参数；V2 只有通用防抖与唤醒节流。
5. **群话题线与黑话联网释义**：群话题线已在 V2 实现；黑话释义的联网参考仍缺。
6. **被戳的多种反应**：V1 有超级反戳、连戳、专属提示词；V2 只有预设短句 + 一次反戳。
7. **主用户语音档**：V1 有"对主用户更常发语音"的一组参数；V2 没有。
8. **Qzone 说说 / 实验开关**：V1 有；V2 **有意不迁**。

## 五、反向：V2 用户比 V1 多出来的

多目标 / 多角色作用域、关系与权限正本（含三档权限与 owner 投影）、诊断域的答疑与修复建议（待接页面）、
生图原生执行（路线队列 + 蒙版与参考绑定的语义）、识屏生产链（解读 + 日记素材 + 主动识屏）、
按角色 × 按任务的模型档案、备份快照与两阶段还原、群图出站与群成员风控、参考素材与衣柜闭环、
表达学习与表情反应、以及一套可复跑的 3,711 用例。

## 六、一句话回答"差了多少内容"

- **配置层面：差 2.9%（29 项）**，其余 96.9% 要么等价、要么有意不迁。
- **页面/内容层面：差 4 类东西**——Token 用量视图、独立排障面板、群聊的三项能力（合并转发投递 / 高密度降载 / 话题线与黑话联网）、被戳与主用户语音的细档；另有 2 项（Qzone、实验开关）是**有意不迁**，不算差。
- 站在用户角度，最扎眼的两个"空位"是：**看不到用量与花费**、**出问题只能看回复链的局部诊断**——这两样在 V1 是有的。
