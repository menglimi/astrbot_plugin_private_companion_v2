# 回复趋势图与模型任务名称

版本：2.1.28，2026-10-15。

## 页面改动

- 每日回复时长图随相邻卡片高度伸展，纵轴与绘图区使用相同基线和网格。刻度统一单位，日期、样本数独立成行；窄屏在同月时显示日数并保留日期范围，跨月保留月日。
- 核心发送返回采用主题实色，历史平台回执采用主题条纹色；悬停或键盘聚焦日期可读出每日 P50、P95、样本数。未观测不绘制零值柱，实际零耗时保留可聚焦读数；全部无时长时显示空状态。
- 模型页补齐主动联系复核、图片审核、图片摘要、内容起草。态势图、快速配置、精确配置、搜索与替换策略使用同一名称表；快速配置只列实际注册任务。后续未知任务也保留在「其他任务」供配置，内部任务键继续显示在诊断位置。
- 维护页的任务提示词和用量明细补齐当前图片、原生视频转述名称。

## 测量边界

核心发送方法返回与平台确认仍为两种测量，不合并为送达。日期下方数量是当日对话样本数；分位值只使用已观测时长。模型内部任务键、配置作用域、Provider 选择与实际运行参数不变。
