# V1 表达学习对照与 V2 链路（2026-10-08）

本轮只读 V1 `_conf_schema.json`、`user_memory.py`、`group_observation.py` 与页面接口源码；不读取 V1 用户数据。V2 保持独立数据根，入口为唯一「陪伴小屋」的学习 → 表达学习。

| V1 能力 | V2 落点与行为 |
| --- | --- |
| 轻量、均衡、深入三档 | `learning_mode`，模型提示分别限定通用节奏、重复场景表达、细分句法与模板；输入包含输出 JSON Schema、原始用户样本和现有规则，候选保留来源句柄 |
| 私聊与群聊学习范围 | 各窗口独立学习开关；群聊可选全部成员或指定账号。角色、平台、账号与精确窗口保持隔离，换群成员不改变该群的工作状态 |
| 私聊与群聊应用范围 | 独立应用开关；私聊／群聊默认允许应用已人工采用的规则，群学习默认关闭。关闭应用后新一轮不再注入 |
| 素材手审 | 默认关闭。观察素材列出来源成员、时间与原文，支持允许、排除、重新允许；审核记录只保存完整内容散列与决定，不保存原文副本 |
| 群增量与每日预算 | 默认 20 条新增消息、每天最多 6 批；成员筛选在计数与取样阶段均生效。预算和进度属于当前角色＋精确群窗口 |
| 发送前表达复核 | 默认开启。有实际规则时才复核；在分段、TTS、发送计划之前完成，最多一次、8 秒上限。失败、非法输出、超时、未成功完成均保留原稿；取消父任务不发送 |
| 抽样应用与反馈 | 已采用规则按使用量和间隔轮换；可信投递回执才计使用量。排除原始素材会停止相关规则；导入的规则包先预览、再逐条采用 |
| 分享包 | 私聊、群聊均有导入预览／应用与导出；支持 V1 分享包外层格式，仅保存抽象表达规则，不导出用户样本、账号或事实 |

## 页面与配置

表达学习页按规则库 → 观察素材 → 学习来源／表达应用／采样与频率／容量与轮换布局。全部 22 项字段使用后端配置合同，保存立即生效并刷新素材状态。素材池读取最多 512 条，每页 24 条，与单次学习批次上限独立。立即学习显示真实样本、审核、新消息与预算状态；学习完成后刷新候选，候选统一在审阅中心采用。

窗口切换通过挂载票据丢弃旧请求，卸载清理轮询。颜色使用主题变量，保留 1559／960／390／320 宽度下的适配，不添加宿主管理、手动窗口绑定或模型注册步骤。

## 实现边界

- V1 的私聊 `owner` 依据关系档案中的 `relationship_role == "owner"`，不是 AstrBot 管理员。V2 当前使用角色下各精确私聊窗口的学习开关，不把管理员或其他权限等级当作 owner；这不是自动复刻 V1 owner 关系筛选。
- 候选规则必须人工采用。学习提炼的是表达形式，不承担事实提取或持久记忆；事实提取与记忆写入仍由记忆领域负责。
- 当前窗口规则不会因同名角色自动扩散到其他窗口，需要显式导入分享包。撤回来源、授权失效或关闭应用时规则停止使用，正常回复继续。
- 主动生成占用后台通道，表达复核使用前台只读任务；被动回复的复核使用后台只读任务，避免父子任务占用同一通道的唯一名额。任务仍受预算、身份、授权、取消与截止时间约束，未获得容量时保留原稿。
- 复核提示要求保留事实、数字、名称、时间、引用、工具结果与承诺；程序额外校验结构化 claims 的 statement 和官方预警全文。普通自由文本的语义等价依赖模型，不能声称已证明。

## 验证状态

当前源码已通过 128 项定向 Python 检查，覆盖原始素材学习、审核与分页、规则采用到回复、分享包应用、群成员与预算、复核失败／超时／取消、主动回执计数、记忆材料回归，以及 SDK 页面接口和模型线路。学习页浏览器 QA 通过：222 次读取、16 次写入，1559／960／390／320 宽度、courtyard／night／contrast／dusk 主题、六个学习子页、22 项配置可达、保存刷新、素材分页审核、学习进度轮询、窗口切换旧响应隔离、错误恢复、卸载清理轮询和无横向溢出均通过。

最终交付包已重新构建并解包验证：1806 个文件、1193 个 Python 文件通过哈希与语法校验；唯一公开页为「陪伴小屋」。AstrBot 宿主检查通过，包含生命周期清理、自动启动、模型会话发现、原生回复开关和天气来源路由检查。群聊换成员后的表达学习绑定校验已修复：同一安装、平台、账号、群、会话和角色绑定下允许成员变化，私聊仍要求精确参与者匹配。

这些检查使用合成模型和平台回执。真实模型、真实群与私聊投递效果未作真机验收，不以合成结果代替。
