# 日记、梦境、阅读与睡眠：完整使用链

日期：2026-09-23。本轮将此前的日记触发、素材收集和写作服务接成可操作、可恢复的生活流程。配置、真实阅读执行、睡眠唤醒、管理 API 和页面均已落地。本文件同时记录本地完整链验证与实际模型调用的不同结果。

## 使用入口

在 AstrBot 的插件页面中打开 **Companion V2 → 日记与生活**。本机入口：

`http://127.0.0.1:6185/#/plugin-page/astrbot_plugin_private_companion_v2/%E6%97%A5%E8%AE%B0%E4%B8%8E%E7%94%9F%E6%B4%BB`

1. 在 V2 插件配置中选定已授权的私聊、原人格、模型和独立 profile，并开启试运行。首次使用建议使用新的 `preview` profile。
2. 页面点击「启动当前配置」。尚未初始化时，页面会依次探测目标、初始化独立库、启动宿主；已有库直接启动。停止和启动均可在本页完成。
3. 展开「日程与偏好」，启用生活执行权限，保存日记时间、时区、睡眠时间与时长，以及自动阅读、独立提取索引的偏好。
4. 「阅读书架」添加带标题的完整原文。可以逐条开始阅读，或开启自动阅读；页面显示每个片段的实际范围、执行状态和主观读后感。
5. 「睡眠记录」开始睡眠，到点自动醒来，或手动提前醒来。睡眠结束后独立生成梦境；取消睡眠不产生梦境完成记录。
6. 「日记与梦境」查看、修改、删除或主动填写正文恢复，也可以手动写当天日记、单独提取索引。
7. 「执行记录」展示持久书写回执。已确定失败的日记可凭原编号与日期显式重试；梦境从对应的已完成睡眠记录重试。结果未知、仍在执行和已成功的原任务不能重新调用。

宿主重载后只读加载已有 profile，页面明确启动后恢复日程。已过时点的新注册从下次开始，停机期间的日期不补写。关闭生活权限会撤销本功能自己发放的精确窗口授权，并停止本功能的在途执行；其他功能的授权不受影响。

## 已落地的调用链

```text
Dashboard 管理员（独立身份）
  ├─ role.life 持久窗口配置 → 配置采用回执 → 宿主已有唤醒循环
  ├─ 原文 Source → 连续阅读片段计划 → 共享模型任务 → 精确范围完成回执 + 主观感想
  ├─ 明确开始睡眠 → 持久唤醒时间 → 可信执行端确认醒来 → 梦境触发
  └─ 日记定时 / 手动触发
       → 同日接纳先持久化
       → 当天全部素材分页汇集
       → 大库存逐批选择原 ID
       → 原人格正文生成与归档
       → 独立摘要 / 梦境碎片提取
```

- 原文收存不代表已读。每个片段最多 6000 个 Unicode 字符，原文的非空连续范围完整入队。完成回执仅在模型成功处理并保存读后感之后提交，不声称读完整本或理解全部内容。
- 读后感作为 `reflection` 单独进入材料，与阅读原文共用来源。提示词保留外部内容、创作、对方表达、计划和主观感受的区别。
- 大库存按模型输入规模分批选材，每批都保留独立任务和用量记录，再从选中的原引用中收束；最终正文仍使用原材料。任一批结果未知会阻止原触发自动或显式重放。
- 活动记录保存 `RoleWorkSpec`，包含原上下文身份、阅读源/哈希/字符范围，或睡眠唤醒时刻。旧 JSON 无这些字段时仍能恢复；旧阅读操作的空感想不改变其幂等参数哈希。
- 阅读中断后保留暂停状态，重启不会根据经过时间补造完成。睡眠恢复时记录实际观察到的醒来时间，随后通过原操作账本恢复梦境状态。
- 书写正文先保存，索引生成是独立任务；索引失败不回滚正文。更正正文使旧索引失效，删除留下显式墓碑，自动写作不能恢复被删日期。
- 撤回整份原文会取消其所有未完成片段，隐藏已保存的感想，并使依赖该来源的日记/梦境不可用。
- 管理操作使用当前管理员身份、原账号/角色绑定、完整 scope、版本和视图令牌。页面动态正文通过 `textContent` 展示；网络丢失回包时保留原操作键。
- 页面兼容 AstrBot 当前桥接直接返回数据的格式，以及旧桥接返回 `status/data` 包装的格式。核心领域包不导入 AstrBot SDK。

本线复用现有配置、Source、活动、操作、模型和日记表，没有新增 SQL 表。当前共享工程内部 schema 为 v20；主动联系等并行工作保持原有归属。
