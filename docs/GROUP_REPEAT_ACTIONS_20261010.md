# 群复读修复（2026-10-10）

用户约定：复读只有跟读和打断两个动作，参考 V1，打断支持自定义文字或本地图片，并排除图片等媒体占位符。

## 行为

- 群消息连续达到阈值后，按 V1 的两种概率选择动作。跟读只发送当前原句；打断优先只发有效图片，否则只发配置的打断语。没有命中时保持安静，不回退到普通模型回答。若已单独开启 Laya 接话决策，可先决定旁听；允许参与时仍只执行这两种固定动作，正文不交给聊天模型生成。
- 明确 @、引用机器人、唤醒词或正在进行的普通会话保留其原准入。普通问题、兴趣词等弱触发不能将已达到阈值的复读变成模型回答。
- `[图片]`、编号图片、语音、视频、文件等占位符不形成复读签名；媒体或不同内容中断连续序列。去除尾部标点后再次排除占位符，避免 `图片！` 误触发。
- 普通插话关闭时，复读仍由自身开关控制。跟读和打断共享每日自主插话额度，每次连续复读最多动作一次；未命中时按配置递增两种概率。
- 决策按原事件持久保存。发送前再次核对当前账号、群、原人格和权限；发送开始后，即使结果未知、处理器重入或最近观察淘汰，也不重放。
- 复读轮不建立 `active_follow_up` 或 `reply_follow_up`。历史 V2 批次中仅由复读触发的回复也排除在普通续话窗口之外。

## 配置

「陪伴小屋」群聊设置的复读分区新增 `group_repeat_interrupt_image_path`。填写宿主机器上的本地图片路径；不读取成员给出的 URL，也不自动复制或读取 V1 的图片。路径留空、文件缺失、图片无效或超过 20 MiB 时使用打断语。

图片用 Pillow 验证 PNG/JPEG/GIF/WEBP/BMP 后以原生 Image 组件发送。发送返回只表示 AstrBot 调用正常返回，不表示平台确认送达；日志与记录保留这一差别。

## 验证范围

定向回归包含原句跟读、自定义打断语、有效／缺失／伪图片、概率未命中、事件及并发去重、未知结果不重放、媒体防误触发和断链、明确会话优先、群与人格隔离、共享每日额度、发送前权限复核及可选记录降级。页面验证打断图进入复读设置区。交付验证使用本次源码构建的新包及 AstrBot 自带 Python，在临时数据根运行；没有真实群发送或模型调用。
