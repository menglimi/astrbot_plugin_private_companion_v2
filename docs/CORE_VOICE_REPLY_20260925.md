# V2 出站语音基础链

日期：2026-09-25。`voice_reply.enabled` 默认关闭。启用后，已封存的私聊和群聊回复按原目标 UMO 选择 AstrBot 当前 TTS provider；每段在同一次 OneBot 调用中依次放文字、该段原图（如有）、语音。分段顺序及原图归属沿用既有发送清单，不在合成时重新生成内容。

合成失败或 provider 不可用时发送原图文；音频只从 AstrBot 临时目录读取，限定非空且不超过 8 MB。等待合成后重新核对授权、原人格和原账号连接，发送前仍执行原投递栅栏。未知 ACK 不重发该段，也不推进后续段。语音开关不改变已初始化运行档的身份指纹，修改后需重载插件。

验证使用 `E:/astrbot/backend/python/python.exe` 和 `E:/astrbot/backend/app`，SDK 导入前将 `ASTRBOT_ROOT` 指向独立临时目录。私聊双 Bot、分段图文顺序、失败降级、首段未知回执、群聊成员会话 TTS 路由、重载与宿主生命周期相关的 41 项定向测试通过；群聊语音用例又连续独立运行 10 次通过。早期一次偶发失败来自本地 reverse-WebSocket 夹具的 20 毫秒 ACK 超时，夹具改为 1 秒后保留了真实超时/未知结果测试。配置 schema 及 9 个涉及文件的 UTF-8、无 BOM、LF 和末尾换行检查通过。

本切片只使用合成音频、模型和本地 socket，没有调用真实 TTS provider 或向 QQ 发送消息。QQ 对图文+语音单条混合消息的支持、实际音频格式、provider 延迟及体积需要现场验收。V1 的按语境/请求选择、概率、语种/翻译、语音独占模式和主动消息语音仍是后续功能，不把当前“开启后逐段附音”视为完整 V1 对等。
