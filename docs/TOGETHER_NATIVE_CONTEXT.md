# 一起房间的 V2 上下文与文字转写

原生房间使用创建时已验证的 AstrBot 人格。只有当前 V2 私聊窗口、角色、Bot 账号与房间绑定一致，且 Together 的现有工具授权仍有效时，才读取该窗口的 V2 本地角色、关系、生活与记忆背景。邀请多人房间仅共享房间内的对话，不读取或写回房主的私人背景。

「接入长期记忆」控制本地长期记忆召回；关闭后角色和关系等其他背景继续生效。「共处补充提示词」支持多段文本，保存后立即生效。工作模式仅读取该窗口此前已授权保存的屏幕分析，不自动启动截图。

「记录房间文字转写」开启后，实际收到的用户文字独立入账，成功发送到房间的 Bot 可见文字随后入账。来源分别为 `conversation.together_input`、`conversation.together_assistant`，历史正文标明 `execution_path=together_room`。不创建核心回复批次、QQ 发送回执或阅读确认，不保存原始音视频。

「同步到 AstrBot 对话记录」仅向精确匹配的现有原生私聊会话追加文字，并标明「一起房间」来源。没有现有会话时不创建会话；会话、人格、授权或参与成员改变后不再同步私人上下文。

旧「记录有意义的共同经历」开关已从原生配置页移除，经历整理由 V2 的文字来源和本地记忆整理功能处理。Live 字幕及嘴型使用本体内部正在运行的 Live 服务，暂停后的实例不接收房间事件。

「一起房间 → 语音链路 → AstrBot STT Provider」指定后，原生手机通话与网页房间都使用这一已加载的宿主语音识别提供商。留空时，原生房间按绑定的准确 AstrBot 会话读取其已启用的默认 STT；不另选全局清单中的任意提供商。小屋指定的提供商不存在或加载失败时，保留该选择并提示检查配置，不悄悄切换到另一个提供商。手机原生端发送录音给服务端 STT，浏览器识别仅适用于网页房间。
