# 模型配置：V1 内容核对与 V2 三页设计

本文件是设计依据，不代表功能已接入 V2。独立交互稿为 MODEL_PAGE_CREATIVE_CONCEPT_20260926.html；示例数据不请求 API、不写配置，也不读取 V1 用户数据。

## V1 实际内容

核对了 V1 的模型页、provider-tree.js、任务分组、语音与生图面板及配置 schema。V1 的模型页已经包含下列内容，设计时不能只照搬 Provider 下拉框。

| 范围 | V1 已有内容 | V2 设计归属 |
| --- | --- | --- |
| 任务分流 | 快速/精准模式互不清空；快速运行分流核心是快速响应、复杂推理、创作、插件识图四项；精准模式逐任务指定。 | 任务模型页的模式切换、六路工作台与任务矩阵。 |
| 独立模型 | 通用 Embedding 供语义召回，资料归档视觉模型需独立指定且没有自动回退；后者按相关能力开关显示。 | 快速工作台的嵌入与资料归档识图两项，保持独立语义。 |
| 任务明细 | V1 定义 40 个路由键，按基础、日程表达、记忆关系、群聊、语义、视觉等分组；单项含主备 Provider、超时、Token、解析结果与测试，特殊任务字段不同。 | 高密度任务矩阵与右侧检查器；窄屏改为列表下方编辑。 |
| 替换策略 | 关键词规则含范围、优先级和匹配逻辑；敏感拒答可换模重试；DeepSeek 高价时段含时区、窗口和替代模型；插件内部流式独立控制。 | 任务模型页的替换策略区与命中预演。 |
| 语音模型 | 中文、日语、英语分别绑定 TTS Provider，可新建、编辑连接和声音、测试与保存；共享 Provider 编辑时需要防止误改其他语种。 | 语音模型页；触发、频控、发送形态等转到 TTS 增强功能页。 |

用户写“快速配置六项”但列出了五个名称。第六项在这版设计中暂定为 V1 已有的“资料归档识图”。这六个入口并非完全同一运行机制：前四项负责快速任务分流，嵌入模型和资料归档识图是独立能力；资料归档识图应在相关能力启用时显示。正式实现前需要确认这项命名与条件显示。

## 三页布局

### 1. 任务模型

左侧导航为独立的“任务模型”页面，页内有“任务模型态势 / 模型配置 / 替换策略”三个锚点。首屏用深色态势板展示六个入口与当前场景流向；切换日程、群聊、创作、表情语义、识图、资料归档时，聚焦对应入口和当前模型。切到精准模式后，态势板改为“当前任务 → 主 Provider → 备用 Provider → 条件替换”，直接读取精准配置，不能继续显示快速模式值。

快速配置直接显示六项 Provider 选择，前四项负责任务分流，后两项标注为独立能力；点击态势节点可定位相应选择项。精准配置采用可搜索、可按分组与状态筛选的任务矩阵。选中任务后，右侧检查器编辑适用字段并显示当前解析值、单项测试与诊断；Embedding 不出现备用/超时/Token，资料归档视觉不出现不适用的备用项。模式切换保留两套草稿，清楚说明运行时只采用当前模式。替换策略仍在本页下半部，以规则列表、拒答替代、高价时段轨道和输入预演呈现；规则命中只临时改写路由，不覆盖任务本身的分配。

### 2. 语音模型

左侧导航为独立的“语音模型”页面。页内三个语种选择键直接切换各自的 Provider、连接、模型、声线、超时与启用状态；右侧保持三语种绑定总览和检测反馈。新建 Provider 从当前语种发起，若编辑已被多个语种共用的 Provider，正式页面应提示共享影响并支持“复制为此语种专用”。设计稿的检测只检查表单完整性，正式接入后需区分连接失败、鉴权失败、无音频和成功。页头提供“前往 TTS 增强”入口，目标页面负责何时说、语言处理、频控、Fish Audio、MiMo 和发送形态；文本转换用的 LLM 仍归任务模型。

### 3. 生图模型

左侧导航为独立的“生图模型”页面。页头先选择“文生图 / 改图”，两者各有独立的提供商优先级队列。每行明确主用或备用顺序、平台、模型/工作流、启用状态；上移、下移和停用立即刷新摘要，停用首项后由下一启用项升为主用。右侧检查器编辑所选提供商的类型、模型/工作流、地址、超时，支持新增、移除与逐项诊断。路由预演显示主用及失败后的备用顺序，但不提交任务。相关功能入口跳往生图触发、权限、提示词、参考图与作品管理的配置页。扩展不可用时，正式页应保留说明和已存草稿，不显示虚假的“就绪”状态；文生图与改图的路线能力须分别校验。

## 视觉与交互原则

整体沿 V2 左侧导航，采用深色态势面板、浅色紧凑表格和青绿/琥珀/珊瑚的状态编码。图形用于解释路由和优先级，不代替字段本身；状态变化不推动布局跳动。桌面任务矩阵与检查器并列，窄屏检查器下移；语音与生图双栏在平板和手机改为单栏。键盘可切换顶部分页、选择任务行并操作优先级，减少动态效果设置下取消非必要动画。

## 原型边界

离线稿只演示信息架构和局部状态：三页切换、快速/精准态势、任务选择、策略预演、语种切换与新增、图片提供商排序和主备预演。所有 Provider、任务与检测结果均为示例。跨页快捷入口在离线稿中打开目标配置预览；正式接入时按 V2 导航路由跳转。V2 是否已具备对应运行能力仍需按实际注册表逐项核对，不能把可见表单误认为已接入。
