# V2 请求级感知对照

日期：2026-09-26。范围仅为 V2 本体普通对话；对照 V1 实现，不读取或迁移 V1 用户数据。

| V1 感知项 | V2 当前路径 | 状态与边界 |
| --- | --- | --- |
| 当前时间、日期、星期、时段、农历 | `conversation/date_context.py` 的请求时投影 | 已接。农历依赖可用的本地库，失败时标为不可用，不猜测。 |
| 节假日、调休、节气 | 角色配置的 `planning_annual_calendars` | 已接明确列出的当天放假、调休、节气及未来三日节气；未列日期和未配置年份保持未知。V1 的固定节气日期表、日期取模黄历以及缺少数据时按周末推断工作日均不迁入。 |
| 平台、私聊/群聊、发言者和媒体 | `model_gateway/perception.py` 与原件上下文 | 已接平台标识、会话类型、实际提供的媒体及群聊发言者归因。V1 的群名等展示字段不作为可信身份依据。 |
| 当前对话、视觉、生图模型 | 请求级目标模型标识、接入模态和本轮工具目录 | 已接实际提交的目标对话模型标识，包括覆盖模型；标识与模态声明不冒充已验证的底层能力。识屏、生图、修图只在本轮实际提供原件或工具时告知模型。V1 的独立视觉转述 Provider 与生图后端名称不对应 V2 当前请求路径，不注入静态可用性结论。 |
| TTS 模型与语种/交付 | `conversation/voice_reply.py` 与宿主投递 | 已接当前封存语音策略的目标语种和交付方式，明确由 TTS Provider 尽力合成；未获成功回执前不宣称已发语音。V1 的独立文本转换模型路径不是当前 V2 语音链。 |
| 世界观适配 | 原人格提示与请求级表达约束 | 已接自然表达约束；V1 按关键词推断奇幻/科幻并替换术语的表不迁入，避免将后台能力转成未发生的角色事实。 |

V1 的环境总开关及各子项开关没有直接复刻。V2 的可信会话身份、来源和工具边界是请求合同的一部分；若要暴露可选感知配置，应先区分“可隐藏的表达背景”和“必须保留的执行边界”，再接入唯一公开的「陪伴小屋」。

本轮使用 AstrBot 自带 Python 和临时数据根完成 12 项定向测试，覆盖模型覆盖路由、媒体/工具感知、日期投影、跨年节气、私聊角色日历与群聊隔离。未运行真实模型、QQ、在线插件或交付包统一测试。
