# V1 学习社交关系网补齐

2026-10-10。用户明确指 V1「学习 → 社交关系网」。它由 `worldbook_member_profiles` 保存人物描述、身份备注、别名、相处边界和重要印象；群成员互动统计不能代替这部分资料。历史页面上的退役标记是旧 UI 设计，不能据此认定用户资料已经迁移或应被忽略。

## 实际缺口

只读读取 V1 当前 `companions.json`：共 196 个成员档案。正式解析排除 5 个已删除节点、1 个已合并节点，剩下 190 个有效节点：24 个角色范围节点、166 个群范围节点。一个群节点属于两个群，所以三个群分别包含 88、74、5 份资料，共 167 个群绑定。原档还有 3 条重要印象，均标记为 internal。

当前 V2 数据库已有三个群范围的成员来源及通用条目来源，缺少角色范围的成员来源。V1 17 条原始世界书人物条目都已有成员档案；旧映射仍生成两套条目，当前账号匹配会被 V2 的重复账号判断抑制。旧转换另把人物描述和身份备注择一取用，未迁移重要印象。小屋迁移页只用原始成员条目数判断能否导入，漏掉只有成员档案的来源。

## 修改合同

- 人物描述、身份备注、补充备注、相处边界与重要印象保存到同一个知识成员节点，旧目录行仍可读取，不增加数据库表。
- 有成员档案时以该档案为准；已删除、合并或禁用的档案不会从旧世界书条目恢复。只有原始条目时，同一账号的多条资料合并为一个节点。
- 普通回复继续按运行时认证账号选择当前发言者资料；姓名只用于本轮明确提及的唯一对象。提示词允许自然参考相处方式，区分内部印象和已确认事实。私人记忆仅进入归属者本人私聊，禁用或隐私标签未知的记忆不进入回复。
- 群范围映射保留身份备注、边界和印象，在对应群、账号和角色下读取。其他群、私聊和角色的隔离合同不变。
- 唯一「陪伴小屋」迁移页按合并后的关系节点计数，包含仅有成员档案的来源，说明迁移内容；原始资料预览不显示正文。
