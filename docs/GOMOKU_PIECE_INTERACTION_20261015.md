# 五子棋棋子交互（2.1.24）

## 行为与职责

`astrbot_host/native_extensions/game/web/native-gomoku-input.js` 负责指针捕获、鼠标/触摸的移动阈值、即时跟手棋子、取消清理与尾随点击。`native-gomoku.js` 保留棋局、取子、落点、确认、放大预览和反馈，真实操作仍由原生房间票据及游戏提供者提交。

- 自由摆子点击棋盒或既有棋子拿起，棋子抬起并显示原位标记；再点一次放回。既有棋子的整个交叉点格可点击，触控无需命中较小的圆形棋子。
- 拖动开始后，原棋子淡出，拿起的棋子立即跟随指针，不使用坐标过渡动画或棋盘边界钳制。棋盘实时标出吸附目标、棋色、坐标及占用反馈。
- 普通对弈可点击落子，也可按住滑动后松手。窄屏和触控默认保留确认操作，并在滑动或预选时显示附近 5×5 交叉点的放大预览。
- 预选、切换棋子和取消只更新反馈节点与控件，不重建棋盘；选择状态不触发轮询重绘。正在拖动时暂停读取应用，提交中展示待同步落点，实际响应返回后再显示权威棋谱。
- 拖出棋盘、拖回原位置、Esc、触摸取消或失焦均还原；已占用落点不发请求。指针捕获保证跨出原棋子后仍能松手，并屏蔽浏览器在同一次手势后产生的尾随点击。
- 棋盒在棋盘上方，棋盒棋子为 34px，取子按钮至少 52px 高；桌面棋盘适配窗口高度，窄屏保留完整棋盘宽度。
- 已结束对局保持只读棋谱；未知响应继续只读核对、不重放操作。既有用户棋谱与 V1 数据不参与界面测试。
