# 自我页与 V1 世界知识对照

更新时间：2026-10-01。核对了 V1 的 `pages/陪伴面板/index.html`、`worldbook.py` 与 `integration_status.py` 源码；本次只检查源码结构，没有读取或迁移 V1 用户数据。

## V1 工作台内容

- 角色资料：姓名、种族、年龄/生日、性别、身份经历、外貌、性格、日常习惯、目标、边界与关键设定。
- 角色衣柜：稳定的服饰倾向与独立维护的具体衣物条目。
- 世界蓝图：世界、时代、规则、基调、活动场景、关系网和补充设定。
- 世界观适配：自动、现代、幻想、科幻、自定义和关闭模式；另有自定义转写提示与逐个平台称呼。
- 引用资料：选择 AstrBot 知识库或文档，作为世界背景参考。
- 用户关系：对用户的称呼、性别、生日、职业、与角色的关系、相处方式及补充资料。

## V2 页面归属

| V1 内容 | V2 入口 | 生效范围 |
| --- | --- | --- |
| 角色资料、世界蓝图、平台称呼与适配 | 「自我 → 角色档案」 | 角色稳定档案随私聊回复封存；适配模式与规则进入回复提示词 |
| 用户关系 | 「自我 → 相处资料」 | 当前角色 × 当前私聊用户；群聊不读取，其他用户不读取 |
| 人格原文导入与可编辑草稿 | 「自我 → 人格底稿」及角色档案整理入口 | 原人格只读；整理结果由操作者检查并显式保存 |
| 世界书与知识库引用 | 「自我 → 世界知识」 | 依据已有知识配置、授权与预算检索，不复制成角色事实 |
| 具体衣物条目 | 「产出 → 衣柜」 | 角色级衣柜；角色档案只记录长期服饰倾向 |

V2 的世界观适配模式保留 V1 的六种选择，并增加 1200 字自定义规则。自动模式在资料不足时要求使用中性说法；关闭模式会忽略平台称呼和适配规则。任何模式只改变表达，不得改变工具或外部功能的实际结果。

V2 使用独立数据根，不读取、迁移或修改 V1 的角色、世界知识、关系资料、衣柜或知识来源数据。页面入口复用各自现有正本，不建立平行副本。
