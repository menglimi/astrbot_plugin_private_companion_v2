`capabilities` 的 Repository 只作为可信控制面的内部持久原语。当前记录固定包选择与本地状态，尚未下载、加载或移除任何真实包；`acquired` 不等于 ready。宿主管理者身份检查、计划授权、实际装卸回执及运行代际必须在下一切片接入后才能开放管理路由。

## Screen 的边界

本轮链路为：合成采集结果及已登记 Source/Asset -> 原件引用检查 -> 同角色本地处理替身 -> 持久解释/反馈意图 -> 原锚点追问。原件文本与资产登记均在临时数据库中；没有实际截图二进制、录屏上传、媒体解码、裁切或脱敏，因此不构成真实屏幕读取验收。

Screen 只保存屏幕材料与解释，不采集电量、手机使用或位置，也不创建人格、长期记忆库、日记定时器、主动循环或独立发送出口。窗口标题不证明用户读完网页，无输入不证明离开；此类理解通过提示词约束，允许模型询问、修订和保持主观表达。

资料读取始终复核当前宿主身份、精确 scope、范围同意和原件治理。新分析还要求能力和角色启用，并在处理前后比较安装、角色、同意、绑定及授权的版本。处理期间暂停再恢复、撤权再授权或换绑都不能让旧结果获得新的执行资格。

丢弃默认保留原件及其引用。已保留资料可以在原授权有效时从基础仓储读取，过期或撤权仍立即拒绝；读取不重新启用 Screen。物理文件清理和备份恢复后的治理传播尚未在本切片实施。
