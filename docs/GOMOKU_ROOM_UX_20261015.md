# 原生五子棋房间体验改进（2.1.23）

## 行为

- 棋线、星位、行列标签、棋子与拖动落点使用同一坐标。棋子落在交叉点上，旧局的格内偏移只在显示时归位，不改写既有棋谱。
- 正常对弈点击空交叉点，走原生 `move` 并自动完成对方应手。自由摆子单独选择，保留双方棋盒、拿起既有棋子和拖动；拖动落点吸附交叉点，拖出棋盘取消操作。
- 窄屏或触控设备默认先选点、再确认，支持更换落点与取消；桌面默认直接落子，可切换确认。方向键选择相邻交叉点，回车触发落子或预选，Escape 清除选择。
- 标记真实最后一手和获胜连线，可以显示手数。双方执色、轮次和结束结果分别依据真实棋局，不以棋子归属染色。
- 自由摆子留下对方回合时，返回对弈提供“让陪伴者接着下”；通过当前房间票据执行原生引擎的对方一手，不额外落玩家棋子。玩家回合、已结束房间和非棋盘游戏拒绝该操作。
- 相同状态轮询保留棋盘 DOM 和焦点，拿子、提交期间暂停轮询，过期读取不覆盖已提交状态。响应丢失后只读核对棋盘，不自动重放落子。
