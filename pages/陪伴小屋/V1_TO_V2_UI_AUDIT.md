# V1 拓展页 → V2：页面与操作对照

核对日期：2026-09-24。对象是旧 `astrbot_plugin_private_companion/pages/陪伴面板`、V2 当前源码与实际管理页，以及本目录中的统一界面预览。

**当前预览还只是页面结构样例，远未覆盖 V1 的操作范围。六组一级导航可以保留，但每组下的工作台、编辑流程、运行记录和异常状态需要补齐。不能继续用几张示例卡片代替完整功能。**

本次静态提取到 V1 的 **17 个一级导航声明、19 个页面容器**；其中创作、生图、现实触及的导航初始带 `hidden`。图片缓存和 QQ 空间有页面容器，但不在这 17 个导航声明中。这是源码结构统计，不是 19 项功能均已验证可用，也不是 V2 的完成率。

核对覆盖静态页面、动态用户/群聊详情、便签、模型和提示词流程，以及 V2 的页面、管理 API、领域服务和当前进度记录。本次没有读取生产用户资料、运行旧管理页写操作、重载 AstrBot 或发送消息。

2026-09-24 首页整合更新：总览、小屋、生活观察及拓展能力（家具）已在当前 V2 设计预览首页统一呈现。下面同步记录结构进展；生活与运行记录仍为示例；配置开关、角色名称和联系参数已取自脱敏本机配置快照，不代表真实运行服务或 V2 拓展适配已经接入。

## 1. 先纠正范围判断

- **衣柜在旧 V1 有实现。** 旧页有衣物管理、服饰倾向、识图入库及穿搭展示；V2 目前只有兼容归属登记。本预览撤下衣橱业务入口是正确的，但衣柜应留在后续功能承接清单里，不能从产品盘点中消失。体素家具存在也不等于衣柜业务或角色换装已实现。
- **“手账”是旧小屋对日记入口的叫法。** `home-room-catalog.js` 的“手账与便签”说明是“翻一页日记”，`home-room.js` 实际读取日记并跳转观察页。未发现单独的手账领域；V2 应继续使用日记、梦境、便签各自的名称和数据归属。
- **V2 已经有两套实际管理页。** “日记与生活”包含归档、原文阅读、睡眠、执行记录和设置；“关系与记忆”当前实际承接关系记录的审阅、采用、更正和撤回。后者的标题不能据此视为完整 Memory 管理页已完成。
- **有些 V2 能力已有服务或 API，但统一界面没承接。** 事实记忆治理、反思失败恢复、成长提案与权限就是例子，应接现有服务，不另造一份浏览器状态作为正式数据。
- **部分旧功能仍缺 V2 业务。** 群聊与群记忆、完整 Calendar/约定、完整身体状态、表达学习、真实拓展装卸、衣柜等，不能只画按钮就标成可用。具体范围以当前进度矩阵及领域代码为准。
- **旧页留有隐藏或历史区块。** `learningPanelSocial` 明确带 `data-retired-worldbook="true"`，实验页还有独立归属；不能按 HTML 中出现过就自动恢复旧关系网、实验规则或已经退役的功能。隐藏的拓展入口也不等于已经退役，需按能力目录确认。

**一个共同前置：现有管理 API 主要绑定当前试运行 profile 的角色与私聊对象。** 统一页要支持多角色、多用户和群，仍需完整的授权目录、选择上下文和读写目标协议。前端新增一个下拉框不能替代这一步。页面切换对象时也不能带着上一对象的草稿或迟到响应继续保存。

## 4. 六组导航的完整展开建议

这是补齐范围的结构建议，不表示下列子页已经实现。二级入口按实际能力和读取权限展示；已有资料的读取与新任务执行分别判断。

| 一级导航 | 应展开的二级工作台 |
| --- | --- |
| 首页 | 同页整合总览、体素小屋、生活观察、家具与能力；完整日程、日记归档、角色资料/世界设定、阅读睡眠、便签提醒及成长由对应入口下钻。衣柜暂不作为可用页。 |
| 人物与关系 | 成员目录（私聊、群成员分开）；对象工作台；群聊工作台；关系理解与审阅。权限管理与关系理解分别维护。 |
| 记忆与经历 | 事实；经历；原文与来源；核心记忆；反思/待处理记录；修订与遗忘。表达学习列为待补领域，不伪装成已经可编辑。 |
| 作品与收藏 | 原稿与作品；素材/相册；资料收藏与原文。按内容 owner 提供版本、来源和操作；阅读执行从同一原文进入生活阅读页，不复制第二份正文。 |
| 一起活动 | 共读、游玩、观看、通话等实际活动入口和会话记录；每项由对应能力决定是否可用。个人阅读不等于已开启共同阅读会话。 |
| 管理与设置 | 能力；通用及分层配置；主动联系；模型路由；任务提示词；用量与预算；运行诊断；身份授权；备份迁移与资料维护；界面与外观。设备和生成后端的专属设置归对应能力。 |

尤其是当前“人物与关系”，下一版应从三张展示卡片升级为：

1. 左侧提供名称/ID/别名搜索、私聊/群成员切换、状态筛选和分页。
2. 右侧保持当前对象，分为概览、身份与授权、关系理解、主动联系、记忆与来源、运行记录。
3. 关系理解复用 V2 已有审阅/采用/更正/撤回流程；事实记忆进入 Memory 的正本和版本操作。
4. 群详情单独管理观察、回复、成员、话题和插话记录；尚未接入的操作在设计范围中标明，不放可点击的假保存按钮。
5. 修改有字段差异、保存回执和刷新后的结果；权限身份、关系站位、记忆事实之间不相互代替。
