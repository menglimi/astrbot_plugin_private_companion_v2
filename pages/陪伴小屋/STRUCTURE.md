## 首页层级

顶部显示当前角色、示例日期与活动；首页、日程、日记提供生活内容下钻。页内定位栏连接“小屋与总览”“生活观察”“家具与能力”，三个区域始终在同一首页中。

| 区域 | 展示内容 | 进一步操作 |
| --- | --- | --- |
| 体素小屋 | 庭院、家具、天气、时段、全景及巡游 | 点选家具打开内容，目录反向定位；外观入口独立 |
| 当前生活 | 活动、心情、心理能量、身体、睡眠、饥饿、位置 | 角色资料、活动详情、生活观察 |
| 今日日程 | 已完成、进行中、尚未发生的安排 | 四项日程与详情共用数据，完整日程下钻 |
| 能力配置 | 当前插件配置、暂停/移除预览态；运行连接待读取 | 能力详情、配置摘要、首页目录 |
| 今日记录 | 日记梦境、生活轨迹、状态变化、交互影响四种视图 | 日记正文、活动来源、阅读睡眠、目标成长 |
| 便签与提醒 | 已存便签、已设提醒数量及空状态 | 编辑便签，不自动创建提醒 |
| 记忆概况 | 已发生经历、尚未发生计划、最近记录与来源 | 原件、人物与群聊目录 |
| 家具与能力 | 全部、基础生活、拓展能力、待处理筛选与搜索 | 打开内容、定位家具、管理能力 |

生活观察不另设一级页面。日常状态、日记梦境、交互影响的查看留在首页；完整归档、记忆治理及运行诊断进入所属工作台。

## 家具映射

场景点选、目录和快捷入口共用一份家具目录与分发逻辑，避免电台打开阅读、花架打开照片等不相干映射。

| 家具 | 内容归属 | 当前预览 |
| --- | --- | --- |
| 日记书桌 | 基础日记、便签与提醒 | 日记和便签可编辑，提醒为空 |
| 生活挂历 | 日程 | 四项安排，区分实际进展与计划 |
| 睡眠与梦境 | 基础生活、Journal | 睡眠快照；梦境与睡眠起止记录为空 |
| 阅读角 | 个人阅读 | 主插件阅读接入当前关闭；章节与便签是保留的展示样例 |
| 相框与相册 | 已有资产 | 两张示例照片，不依赖生图能力启用 |
| 成长花架 | Growth | 暂无目标或提案，不伪造进度 |
| 见闻电台 | 见闻来源 | 新闻配置开启；预览尚未读取新闻记录 |
| 创作书架 | Content | 原稿、作品、能力状态 |
| 画面工作室 | Image | 能力详情、已有相册、状态管理 |
| 共处电话 | Together | 能力详情、现有共读活动 |
| 游戏棋桌 | Game | 服务、私聊/群房间与 7 类游戏配置开启 |
| 屏幕台 | Screen | 配置开启，显示屏幕识别与来源开关；连接状态待读取 |
| 现实设备台 | Reality | 配置开启，区分只读与管理员控制；设备状态待读取 |
| 直播与表演 | Live | 展示已有 Live2D、SoulLink、B 站等配置；目录入口暂无场景家具 |

目录共 14 项：7 个基础生活入口、7 项可选能力。“待处理”包含暂停、待连接和待授权。陈设衣柜、灯、茶几和地毯不计入能力；衣柜可保留视觉开门，不提供换装业务。

## 交互与数据规则

- 场景常驻首页，目录常驻下方。WebGL 失败时提供重试及完整目录，全部内容仍可访问。
- 观察分类、家具筛选、搜索、天气、时段及首页能力更新局部刷新，保留场景实例与视角。定位家具才主动移动镜头。
- 配置快照会把 Content、Image、Together、Game、Screen、Reality、Live 的配置开关与关键参数映射到能力目录；暂停能力保留家具；移除可选能力时家具退出场景，目录保留恢复入口及已有资料；恢复后重新展示。基础日记、便签、个人阅读和已有相册不受影响。
- “布置房间”使用独立工作区，无模态遮罩。桌面将场景与工具并排，手机保留上方场景、下方工具独立滚动；保存和取消固定在顶部。继续使用原有 canvas，不重新创建三维场景。
- 已接入房屋风格、家具选择/外观/款式、沿墙挂件、实际拖动、方向微调、旋转、收纳/摆回和布局撤销重做。方向键、R、Ctrl/Command Z 可在场景中操作。
- 调整只影响未保存草稿。保存按角色写入浏览器并返回首页；取消或 Esc 恢复进入前的完整布局和时段。收纳状态独立于能力启停，目录可继续打开内容；恢复能力不会自动取出用户收纳的家具。
- 生活记录使用 9 月 23 日示例日。天气与时段为独立环境预览，不虚构新事件，不改写日记历史天气。
- 生活轨迹只展示已完成或进行中的个人活动。散步、补写日记仍为计划，不计入已发生经历。
- 当前只有一份心理能量及状态快照，暂无日内变化；交互影响没有来源时为空，不推算情绪变化。日记梦境保留主观感受，不自动视为现实事实。
- 日记与便签摘要读取已保存正文并转义；便签可以清空。编辑不制造经历，不生成提醒。
- 使用独立 localStorage 键。望舒仅展示空状态，不作为配置中的第二个角色，也不显示当前配置角色的记录；导出仅含预览设置，不代表安装备份。
- 全部入口可经键盘操作；详情支持 Escape 和焦点返回。减少动态效果同时控制三维巡游、降水及页面滚动。

## 全局导航

左栏是唯一的导航区，分三组；标题不省略任何一组（此前第一组是 untitled，六项入口悬在顶部没有分组名，而下面两组有）。

| 左侧分组 | 本体入口 | 内容归属 |
| --- | --- | --- |
| 生活 | 状态与日程、日记与生活 | 角色状态、日程与公开文案、日记与睡眠（二级视图，点按走 `#life/state`、`#life/diary`） |
| 专题配置 | 关系网、主动与联系、事实与经历、学习与反思、模型与连接、治理与维护 | 关系审阅、来源记忆与治理、联系节奏、学习与成长、模型路线、运行诊断 |
| 能力配置 | 感知、理解、决策、行动、产出、表达、自我 | V2 原生感知与语义、群聊参与判断、主动行动、内容产出、表达与投递、人格与世界资料 |
| 设置 | 开始使用、外观与设置、账号与会话、资料与维护 | 运行接线、显示维度、绑定与运行、记录来源与备份 |

桌面左栏完整显示这些入口并可滚动；≤1120px 收成图标栏，≤760px 压成一条可横滑的「图标 + 文字」条（品牌与搜索固定两端，滚动条隐藏），19 个入口不再堆成三行、也不再只剩图标。首页家具目录提供拓展使用及状态入口，提供方专属配置仍由其插件管理。旧 `#library`、`#activities` 和 `#manage/capabilities` 统一跳转家具目录。页面没有聊天输入、麦克风录入或发送入口，交流留在 QQ 等原渠道。

「全部功能」浮层（`navigationDialog`）由 `rail-foot` 里的「全部功能」按钮打开，内容由 `shell.js` 的 `railGroups()` 生成，与左栏同一份分组与标签；左栏没有的二级页（用户、群聊等）自动归入「其他入口」。

## 离开页面前的未保存提示

`page-guards.js` 是页面级注册表：每个自带草稿的编辑面导出 `isDirty()`，`app.js` 在 `pageLeaveDecision`（路由跳转）、`guardUnsaved`（左栏与家具）、`beforeunload`（关标签页）三处汇总。当前登记：布置房间、角色档案草稿、感知配置、模型与连接、语义校验、开始使用，另有工作台内核与状态页/天气源页各自的内建检查。

## 视觉与交付

沿用浅蓝背景、紫灰和绿调、紧凑内容卡片及纸质阅读感。小屋为本地 Three.js 体素场景，庭院草地、小径、植被和雾色共同承托。六种天气、四个时段及减少动态效果保留。新屏幕台和设备台沿用三维空位与碰撞避让。

桌面为场景主区、右侧概览、三列生活观察、四列家具；平板和手机按内容重排，保留全部入口。源码为 index.html、styles.css、room-editor.js、app.js 和 assets/，文本 UTF-8，无外部 CDN。字体、图标、素材来源与许可随 assets/ 保留，场景源码位于 assets/voxel-source/，编译产物可直接运行。
